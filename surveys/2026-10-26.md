## VLA (Vision-Language-Action) 関連ニュース — 2026-10-26

- **設定の細部が成績を丸ごと飲み込む2本 — fp32 マスターコピーと Coupling Execution Horizon and Sampling Depth**（分類: 論文, 2026-10-22〜23）
  - 共通するのは、**アーキテクチャでもデータでもなく、学習・配備時の数値設定ひとつで成功率が桁違いに動く**という指摘。片方は学習側のバグ、もう片方は配備側の設計変数
  - **Full-Weight VLA Fine-Tuning Without an fp32 Master Copy** が強烈。学習対象の重みを bf16 のまま持って fp32 のマスターコピーを置かないと、AdamW は更新を直接 bf16 へ書き戻すため、**重みの 1/512 未満の更新が黙って丸め消される**。LIBERO の実測で、100 ステップごとのプローブが**更新の 79% 以上が消えている**ことを捉える
  - 怖いのは普及度で、**公開 VLA コードベース 12 本のうち 9 本**が既定ないし文書化されたレシピでこう学習しており、**LeRobot の SmolVLA 既定値と π₀/π₀.₅ のガイドも含む**。Hugging Face Hub では**全重み学習の SmolVLA ファインチューンの 99%** がアクションエキスパートを bf16 で保存、**直近の π₀.₅ ファインチューンの 84%** が bf16 フラグを立てている
  - 効果は、学習率を 1/10 にした未学習寄りの設定で LIBERO-Object が **4.3% → 49.3%（SmolVLA）**、**5.1% → 80.9%（π₀.₅）**。既定学習率でも π₀.₅ は **89.0% → 97.7%**。しかも SmolVLA 既定率では**開ループ 50 行動チャンクで +10.2pt、10 行動ごとに再計画すると +4.2pt** と、再計画が誤差を隠していたことまで見える。**直し方は「学習中は重みを fp32 で持つ」だけで、LeRobot の SmolVLA なら1行**
  - **Coupling Execution Horizon and Sampling Depth** は配備側。flow matching VLA では**ソルバの刻み数と実行ホライズンが独立に決められ、刻みは忠実度のため深いまま**にされてきた。ここに**符号反転**があるという主張で、粗い数値積分は**速い再計画の下では精度を損なうのに、開ループで長く走らせる下では成績を明確に改善する**
  - 幾何的な説明が効く。数値的な打ち切りは**不変な軌道重心のまわりで行動の横方向のばらつきを縮める**ため、開ループの累積ドリフトを抑える暗黙の正則化として働く。LIBERO・RoboTwin 2.0・実機 Franka、π₀/π₀.₅/GR00T で、**学習もアーキ変更もなしに成功率を上げつつ推論遅延を大幅に下げる**。10/23 の When One Step Is Enough が「大きな VLA では1ステップ生成で足りる」だったのに対し、こちらは**刻み数を精度予算ではなく分散の調整つまみとして使う**側
  - 出典: [arXiv:2610.31859](https://arxiv.org/abs/2610.31859), [arXiv:2610.32102](https://arxiv.org/abs/2610.32102)

- **凍結ポリシーの内側から失敗を読み、戻ってやり直す — Backtrack と Do VLAs Know They Will Fail?**（分類: 論文, 2026-10-23）
  - **Backtrack** は復帰を安く作る。従来は**復帰デモの収集・再学習・推論時の別モデル**のいずれかが要ったが、提案は**凍結 VLA の既存の内部表現を読む小さな失敗予測ヘッド**のみで、**学習は凍結ポリシー自身のロールアウトに成否ラベルを付けたものだけ**。予測確率が閾値を超えたらポリシーを一時停止し、**アームが直前に通った軌跡を逆にたどって**から、手を加えていないポリシーへ制御を返す
  - ヘッドの追加パラメータは**本体比 0.48〜0.88%**。flow matching 系の SmolVLA・π₀.₅ と自己回帰の π₀-FAST という2系統で検証し、3ポリシーとも最も失敗する LIBERO-Long で**失敗率を 19〜48% 削減（成功率で最大 +7.4pt）**。既に 85〜99% の短時間スイートでは効果は小さく、MetaWorld では SmolVLA の**12通りの制御設定すべてが無支援を上回る**
  - **Do VLAs Know They Will Fail?** は同じ内部表現を解釈側から扱う。OpenVLA の活性に対する**疎オートエンコーダ (SAE) 表現が結果予測的な情報を含み、不可逆な状態に入る前に失敗を予測できる**ことを示したうえで、**成功・失敗の特定の段階と結びつく個々の SAE 特徴を同定**し、活性が大きく変化する時間区間を局在化して反復する行動パターンを掘り出す。さらに VLM ベースの解釈パイプラインで**そのパターンに自然言語の記述を与え、held-out 区間で対応を検証**する
  - 10/23 の Progress Probes が「ポリシー活性から進捗を線形プローブする」、10/22 の Post-hoc Epistemic Uncertainty が「不確かさを安く作る」だったのに対し、こちらは**予測の先に物理的な復帰動作を接続する**側と、**なぜ失敗するのかを人間可読な振る舞いまで降ろす**側。10/20 の SteerAct が SAE 特徴を介入に使ったのと同じ素材を診断に使っている
  - 出典: [arXiv:2610.32941](https://arxiv.org/abs/2610.32941), [arXiv:2610.32208](https://arxiv.org/abs/2610.32208)

- **RynnUnify: 推論器と動画生成器を噛み合わせた 16B の「統一具身ブレイン」を公開**（分類: 製品 / 論文, 2026-10-22〜23）
  - Alibaba DAMO Academy による 16B の統一具身モデル。構成は **Mixture-of-Transformers で、8B の自己回帰 Reasoner と 8B の rectified-flow 動画 Generator**（Cosmos3 Nano 上、バックボーンは Qwen3-VL-8B-Instruct）。**サブタスク推論と動画予測を交互に回し、生成した結果を次の計画の条件に使う**という構図で、cross-chunk のシーン記憶・self-forcing 学習・可変長の持続時間が長時間の視覚計画を支える
  - 拡張が2つ。**agentic 拡張**は RL で「**未観測の状態や相互作用の結果を推論するときにだけ動画予測を使う**」選択を学ぶ。**world-action 拡張**はその理解と予測をロボット制御へ落とす
  - 数字は、評価した統一マルチモーダルモデル中で具身理解の平均が最高、長時間視覚計画 **Rynn-VP で Cosmos 3 Nano 比 +9.75pt**、agentic 拡張が **Rynn-GEU 平均で直接推論比 +6.0pt**。world-action 拡張は **RoboCasa365 の選抜 20 複合タスクで 51.5%**、**実機3タスク平均 46.7%**（Astribot S1）
  - 留保は2つ。**実機 46.7%（3タスク）と RoboCasa365 51.5% は絶対値として高くなく、20 タスクの「選抜」基準も示されない**。もう一つはライセンスで、**コードは Apache-2.0（VisualPlan は OpenMDW-1.1）だが、重みは alibaba-damo-academy 独自ライセンス**で Apache ではない。2月の RynnBrain とは別物で、重みは 10/22 に Hugging Face へ、10/24 に更新
  - 出典: [arXiv:2610.32965](https://arxiv.org/abs/2610.32965), [GitHub](https://github.com/alibaba-damo-academy/RynnUnify), [Hugging Face](https://huggingface.co/Alibaba-DAMO-Academy/RynnUnify-Base)

- **フロンティアモデルを頭に据えたとき、何を渡すか — FORCA（力）と LogLook（記憶とトークン予算）**（分類: 論文, 2026-10-22〜23）
  - **FORCA** は 10/19 の HexaShell が示した壁——「**限界は推論ではなく接触**」——に直接当たる。視覚観測に加えて**手首の力/トルク (F/T) 計測をコーディングエージェントの入力に入れ**、接触探りと力応答的な動作の Python プログラムを書かせる。実行と実行の間に**力の記録を視覚的な結果と並べて失敗を診断し、動作と力フィードバック制御のロジックを両方書き直す**
  - 要らないものの列挙が強みで、**デモもタスク固有の学習もシミュレータも不要**。実機5タスクで、精度の改善・物体や面の性質の変化への適応・面の変動と物体運動の下での接触調整の3形態を示し、同一エージェントの視覚のみ版に対して把持精度と成功率が上がり、**拭き取りと皮むきで接触のロストが減る**。ただし**絶対的な成功率は抄録に出ておらず、比較対象は自前の ablation のみ**
  - **LogLook** は渡すものがトークン予算と記憶。フロンティア VLM はタスク固有の学習なしに計画できるが、**エピソードをどう覚えるかは未解決**で、毎ステップ書き直すメモは「何をして何を学んだか」の保持にも「どのフレームを見るか」の選択にも向かない、という整理
  - 提案は**実行ログとモデル自身の過去のメモを記録として保持したまま、どこを見るかはモデルに決めさせる**。フレームは**変化を予期した箇所でのみ返され**、デモはまず飛ばし読みしてから選んだ部分だけを精査する。ベンチ付属のモーションプランナ下で、**メモのみの記憶と同等の成功率を 43% 少ないトークンと半分未満の画像で**達成し、記憶や視界の不足による失敗が大きく減る。直接制御では **RoboMME テストセットの 93.5%** を解く
  - 10/25 の FastHarness が「同じ監督者を呼ぶ回数を経験で減らす」だったのに対し、こちらは**入力チャネルを一本足す側**と**同じ予算の配り方を変える側**
  - 出典: [arXiv:2610.31841](https://arxiv.org/abs/2610.31841), [arXiv:2610.32348](https://arxiv.org/abs/2610.32348)

- **Not an Accident: 安全フィルタそのものが攻撃面になる**（分類: 論文, 2026-10-22）
  - 安全フィルタは「生成された制御が衝突を起こさない」数学的保証を与える技術として普及しているが、**その保証が成り立つのは安全パラメータが正しく設定されている場合だけ**。そして正しい設定は**タスクと環境に固有で、多様な配備にまたがって決める一般的な手法が存在しない**。結果として、出荷時に積まれた安全フィルタが特定の場面で破れる
  - 攻撃面としての指摘が鋭い。破れを突くのに**追加の権限も能力も要らず、通常のユーザ対話だけでよい**。**goal insertion attack** を定式化し、与えられたタスクと環境に対して脆弱な目標を自動で見つける **SIREN** を実装
  - 結果は、**SPARK データセットの脆弱なシナリオすべてで攻撃を発見**し、ベースライン比で**3倍の攻撃を見つける**。実機のヒューマノイドに対しても、タスク実行中に衝突を起こさせる攻撃を生成できた
  - 10/20 の PhantomTac が**センサの物理層**、9/27 のバックドアや 10/19 の Visual Task-Redirection Attacks が**モデル側**を狙ったのに対し、こちらは**安全機構それ自体がリスク源になる**という第3の面
  - 出典: [arXiv:2610.31923](https://arxiv.org/abs/2610.31923)

その他、**RepresentNav**（複数の視覚基盤モデルの全深度の特徴に注意を張り**ポリシー自身の目的から表現空間を構築**、同じ空間で次時刻の表現を予測する潜在 CoT を JEPA として同時学習。**VLNVerse fine-grained 83.80%（従来 SOTA 比 +20.05pt）**。夢みた潜在1枚が**教師を与えていない 3D 占有まで復号でき**、衝突が 1/4 減, [arXiv:2610.31762](https://arxiv.org/abs/2610.31762)）、**EgoForesight**（一人称動画の行動ラベルのノイズに応じて教師の与え方を割り当て、結果を補完的教師に使う。3万時間事前学習で実機開ループ MSE −20.5%、RoboCasa few-shot +8.1pt, [arXiv:2610.31845](https://arxiv.org/abs/2610.31845)）、**NimCritic**（800時間超の学習動画と 19,618 フレームの LOOM。VPB 終端成功精度で GVL (GPT-6-Sol) 比 約+65%, [arXiv:2610.32776](https://arxiv.org/abs/2610.32776)）、**DexPort**（収集と配備で同じハンド実機を使う携帯インタフェース。指令値を使うと 11% → 64%、野外データで 36% → 78%, [arXiv:2610.32969](https://arxiv.org/abs/2610.32969)）、**WorldMirror**（real-to-sim を**実行可能な world program の反復改良**として定式化, [arXiv:2610.31834](https://arxiv.org/abs/2610.31834)）も候補でしたが、分量の都合で見送りました。

誠実な否定的報告として **TTT in VLA Models**（InternVLA-A1 と π₀.₅ に Test-Time Training を入れたが、**現在の規模ではデモに基づく対象選択は一貫して成立せず**、短い系列・全軌跡の勾配接続・対照正則化のいずれも明確な改善を示さなかった, [arXiv:2610.32094](https://arxiv.org/abs/2610.32094)）、実験を伴わない立場表明として **When Human Corrections Travel**（連合学習で人間の修正由来の適応を共有すると、**平均成功率を上げる更新が稀な安全介入を潰したり別機体で危険な応答を生みうる**, [arXiv:2610.32888](https://arxiv.org/abs/2610.32888)）も出ています。
