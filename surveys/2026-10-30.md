## VLA (Vision-Language-Action) 関連ニュース — 2026-10-30

- **推論トレースを「正しいか」ではなく「どれだけ効かせるか」で扱う2本 — CoC-CFG と CoRAct**（論文, 10/29）
  - **CoC-CFG** は推論スパン有無の文脈間で classifier-free guidance をかけ、その重み選択を**行動価値をブートストラップせず実測する MDP** として解く。Alpasim 閉ループ **300中262通過**（元ポリシー252）、Waymo 隠しテストで **rater feedback 8.135（既発表最良 8.079）**
  - **CoRAct** は ECoT の movement と waypoints を**検証可能な信号**に変え、報酬で初期ノイズ分布を group-relative 最適化。外部 VLM が与えた ECoT も実行可能な挙動に接地できる
  - 出典: [arXiv:2610.40002](https://arxiv.org/abs/2610.40002), [arXiv:2610.39543](https://arxiv.org/abs/2610.39543)

- **「未来を見る」ことの収支を決算する2本 — Utility-WAM と SaiVLA-JEPA**（論文, 10/28〜29）
  - **Utility-WAM** は未来条件付き/なしの**行動差分 Δa** を測る。平均は ±0.8pt なのに遅延 1.7〜1.9倍、そして精密タスクで **Press Stapler −54.0pt** など、独立学習した複数 WAM で同じ2タスクが壊れる。残差アダプタ＋事前生成ゲートで**動画生成の 75.5% を省き**遅延 −38%、RoboTwin 2.0 93.3%
  - **SaiVLA-JEPA** は誠実な否定報告。現在の JEPA 条件付けは 71.6% → 82.5% と効くが、**将来予測の監督は検出可能な利得なし**
  - 出典: [arXiv:2610.39367](https://arxiv.org/abs/2610.39367), [arXiv:2610.38508](https://arxiv.org/abs/2610.38508)

- **成功率の外側でモデルを選ぶ／積む — RoboSeed と QbD-VLA**（論文, 10/28〜29）
  - **RoboSeed** は能力・学習費用・配備費用・検証済み研究価値・再現証拠の5軸。未測定は未測定のまま明示し、**総合順位そのものを出さない**
  - **QbD-VLA** は短い閉ループ評価の成功率で混合精度を割り当て、重み約4bit・活性6bit未満。ただし実機では **X-VLA は無劣化・π₀.₅ は失敗**で、配備前の実世界評価が要ると自ら締める
  - 出典: [arXiv:2610.40026](https://arxiv.org/abs/2610.40026), [arXiv:2610.38661](https://arxiv.org/abs/2610.38661)

- **Gym-Anything for Robotics: シミュレータを作る仕事をコーディングエージェントに移す**（論文, 10/29）
  - 対象を**米国 GDP データ**で選び、敵対的な作成-監査ループで検査。**RoboWorld は最良のフロンティアモデルでもテストタスクを1つも解けず平均報酬 0.06**
  - 出典: [arXiv:2610.40565](https://arxiv.org/abs/2610.40565)

- **「働き」を単位にする側と、オーケストレータをクラウドで売る側 — AGIBOT と Gemini Robotics ER 2**（業界動向/製品, 10/28〜29）
  - **AGIBOT**（10/29）は **Worken = 稼働台数 × 自律稼働時間 × 出力効率比** を提案し、WRAM ベースの **GO-3 Preview**、WITA-Omni 1.0、AHA3、G2 Max、**年内完全オープンソース予定の Link-U OS 1.0** を同時発表。ただし GO-3 の提供時期も Worken の適用値も未公開
  - **Google Cloud**（10/28）は **Gemini Robotics ER 2 をパブリックプレビュー**。**VLA を航法 API と並ぶツールとして呼ぶ上位層**で、重要イベント同定 91.3%・MAFD 0.96秒・実行速度4倍。計画はクラウド、制御はエッジという線の引き直し
  - 出典: [The Robot Report](https://www.therobotreport.com/agibot-introduces-worken-measure-robot-productivity-innovation-day-2026/), [Google Cloud Blog](https://cloud.google.com/blog/products/ai-machine-learning/gemini-robotics-embodied-reasoning-2-is-now-available-on-google-cloud)

その他、Robotic Data Inoculation、PASA-KV、Beyond Behaviour（VLA は危険を内部で登録しても既定応答はタスク実行のまま）、Decoding Geometry Not Tokens、GenSight、BURGER、ReSTEP/REMORA など8件は分量の都合で「その他」扱いにしました。OpenFlyV2（10/17 X-Fly）、BEHAVIOR-1K 評価（10/26）、UMI-Live（10/29 OpenJaws）、EmbodiExp / Ask to Evolve、Teradyne×Sereact 提携は重複または技術的開示不足のため除外しています。
