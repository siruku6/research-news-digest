## VLA (Vision-Language-Action) 関連ニュース — 2026-10-20

- **汎用モデルは専用ポリシーに追いつくのか — The Bitter Lesson Comes to Robotics と GPT-6 Astra Is a Native Visuo-Tactile Policy**（分類: 論文, 2026-10-18〜19）
  - **Bitter Lesson** は RoboDojo の6タスクを**実機**で、7モデル × 複数の reasoning-effort 設定で評価。結論自体は穏当で「直接制御はできるが、実用的な行動予算内で完了するには精度も効率も足りない」
  - 効くのは水準ではなく**時間微分**。2026年7月→9月の3か月で性能の**倍化時間 44.5日**、最良の実行レートは **4.4倍**、最低実行コストは **1/6.2**。CoRL 2026 の The Action Gap ワークショップ投稿で、産業自動化の便益と悪用リスクの両面を追跡する動機を明示している
  - **GPT-6 Astra ... Visuo-Tactile** は別角度から同じ問いに当たる。視覚ベース触覚センサの **RGB 画像を既存の視覚入力口にそのまま流す**だけで Astra が接触手がかりを解釈し、few-shot 閉ループ制御が成立する。UniVTAC / OpenViTac の19タスク（設定あたり210シード）で **93.8% / 81.8%**、専用ポリシーの最強報告値を **+22.9pt / +13.1pt** 上回る
  - ただし**視覚のみでも 76.3% / 80.6% で同じベースラインを超えて**おり、著者らは「細かい視覚が触覚の欠落を部分的に代替しうる」ことと**ベンチ飽和の兆候**を同時に指摘。全てシミュで実機検証は今後
  - 10/17 の AA-Robotics が第三者の横並び採点、10/19 の HexaShell が壁の所在だったのに対し、こちらは**進歩の速度**と**専用ポリシー優位の切り崩し**
  - 出典: [arXiv:2610.25287](https://arxiv.org/abs/2610.25287), [arXiv:2610.26846](https://arxiv.org/abs/2610.26846)

- **Learning from Fleet Experience: 96台のロボットが、人の介入なしに互いの経験で賢くなる**（分類: 論文, 2026-10-19）
  - 展開中の経験を学習に回す道は従来「**遠隔操作者が監視して失敗時に介入する**」前提で、台数が増えると人手側から破綻する、という問題設定
  - 提案する CEL は各機の実行経験を共有して**共通ポリシー**を更新する枠組み。中核の FERT は**失敗した文脈**を手がかりにフリート共有の成功軌跡から該当区間を検索し、その行動を教師に使う。**追加のデモも修正行動も集めない**。FATS が局所的な中断を許容しつつ収集・最適化・配布を非同期で回す
  - 実機5タスクで、**学習データ収集に参加していない機体**上で120試行ずつ評価して成功率 **93.3〜99.2%**。1台あたりの収集時間を固定したまま**台数を増やすほど成績が上がり**、多段の携帯電話梱包は 96台で **79.2% → 98.3%**
  - 9/24 の CARE が単機の自己進化だったのに対し、こちらは**台数方向のスケール則をデータ収集の側に持ち込んだ**格好
  - 出典: [arXiv:2610.25736](https://arxiv.org/abs/2610.25736)

- **GazeAct: 人の視線を学習時だけ借りて、推論は視線なしで動かす**（分類: 論文, 2026-10-17）
  - 画面越しの遠隔操作中に、**オペレータが見ているロボットカメラ映像の上で視線を 300Hz 記録**。40タスク・5ドメインで12,000デモを収集し、操作者が選んだビューの視線を**残りの同期カメラへ転写**して多視点で整合した目標を作る
  - 肝は使い方で、視線は**言語条件付き視覚アテンションを正則化する学習時ターゲット**としてのみ使い、**推論時は視線不要**。アブレーションでは**ソフトな監督として使うのが最良**で、汎用のアテンション事前分布より実測の人間視線が強い
  - 実機18タスクで平均成功率 **48.1% → 58.6%**（最大 +25pt）、LIBERO-Spatial **57.9% → 69.6%**、別の VLA バックボーンにも転移
  - 10/15 の FoveaVLA が「どこを見るかをポリシー自身に予測させる」だったのに対し、こちらは**人間の視線を外から教師信号として与える**側
  - 出典: [arXiv:2610.24507](https://arxiv.org/abs/2610.24507)

- **Coverage Shift: ポリシーが上手くなるほど、残った失敗は見つけにくくなる**（分類: 論文, 2026-10-17）
  - 問いが鋭い。「**より良いポリシーは、より監視しにくくなりうるか**」。VLM の成功判定器を固定したままポリシーだけを改善する統制実験で答える
  - トレイ配置の20シード実験で、シミュ検証済みの成功のみを使って学習すると成功率 **66.8% → 97.0%**、見逃された hover 失敗は全実行の 5.0% → 0.9% に減る。ところが**残った hover のうち判定器が通してしまう割合は 31.1% → 50.0% へ上がる**
  - 原因は残存失敗の**性質が入れ替わる**こと。学習後の失敗はトレイの縁より下に寄り、掴んだキューブの陰に隙間が隠れる。境界プローブは**縁下 hover を 148/160 受理、縁上は 0/160**。9判定器・1,392刺激まで広げても同じ診断が出る
  - 提言は実務的で、**絶対的な見逃し・条件付き見逃し・監査カバレッジを併記せよ**。10/12 の RESCUE が「アラームに従う価値」を測ったのに対し、こちらは**判定器の有効性が学習によって動く**こと自体を扱う
  - 出典: [arXiv:2610.24801](https://arxiv.org/abs/2610.24801)

- **PhantomTac: 0.5mm の磁気タグを貼るだけで、触覚センサの読みを乗っ取る**（分類: 論文, 2026-10-19）
  - 磁気式触覚センサは遮蔽に強く3次元力が取れるため採用が進むが、**磁場を外から書き換えられる**という物理層の穴がある
  - 攻撃は**厚さ約0.5mm・電池不要の磁気タグを対象物の表面に貼るだけ**で、バーコードシールの下に隠せる。貼ったら立ち去れる（deploy-and-forget）うえ、**ロボット本体には一切触れない**ので従来のサボタージュより遥かに秘匿性が高い
  - 効果は方向で変わり、**法線力を偽装すると対象を握り潰し、せん断力を偽装すると滑らせて落とす**。市販センサをリバースエンジニアリングしてタグを設計し、把持位置ずれ 8mm 以内で**成功率 95% 超**、既存の対磁気干渉機構を突破。併せて多モーダル整合性による防御を提案
  - 9/27 のバックドア検証や 10/19 の Visual Task-Redirection Attacks が**モデル側**を狙う攻撃だったのに対し、こちらは**センサの物理そのもの**。触覚を足す流れ（9/29 Uni-VLaT、10/16 Neuron AI）に対する攻撃面の指摘にあたる
  - 出典: [arXiv:2610.26174](https://arxiv.org/abs/2610.26174)
