## VLA (Vision-Language-Action) 関連ニュース — 2026-10-06

- **What the Guard Misses, the Robot Executes: 「婉曲に頼まれた有害タスク」はガードを素通りする**（分類: 論文, 2026-10-05）
  - VLA は指示を拒否する機構を持たないため、有害要求の遮断は外付けのモニタ任せになっている。そこで**タスク自体は固定したまま「意図をどこまで明示するか」だけを変える**実験設計で、モニタが実際に止められるのかを検証
  - π0.5 は意図の明示度によらずタスクを完遂し、その頻度は無害な対照条件と同等。テキストガードは露骨な要求はほぼ全て検知する一方、**含意的な要求では最大95%が「タスク完遂かつ無検知」で終了**。ロボット指示文で再キャリブレーションしても最大90%が素通り
  - 活性値の監視でも塞がらない。線形プローブはベースの言語モデル・VLM 上では有害／無害をほぼ完全に分離できるのに、**ロボット学習後にその分離性が低下**する（2つのモデル系列で確認、含意的有害で最も顕著）
  - 10/05 掲載の SocialVLA が「人間の反応を実行時の停止信号にする」話だったのに対し、こちらは**その手前の入力側ガードが embodied 設定で機能していない**という指摘
  - 出典: [arXiv:2610.05818](https://arxiv.org/abs/2610.05818)

- **Beyond LLM Serving: VLA の推論負荷は LLM サービングの設計点から外れている**（分類: 論文, 2026-10-04）
  - 制御周期が推論のデッドラインになり、超過すると古い観測で動くため成功率が落ちる。だがロボット1台は**バッチサイズ1**での推論であり、これは LLM サービング基盤が想定する設計点の外、という問題提起
  - 代表的な VLA 4種を、エッジ GPU サーバと車載級 SoC 2種で計測。単発推論のプロファイリングに加え**43,200 エピソードの閉ループ実行**で特性化
  - 知見は3点。①**行動テンソルの次元数**がその段階をメモリ律速にするか計算律速にするかを決める ②プラットフォームの性能バランスでそのボトルネックが移る ③GPU 周波数スケーリングにはプラットフォーム依存の「エネルギー×レイテンシの最適点」がある
  - 閉ループでは推論と動作実行のオーバーラップが**精度・速度・エネルギーの三すくみ**を生み、配備 SLO をまたいでパレート支配的な構成は存在しない。高速化手法の提案ではなく、ハードと実行ポリシーまで含めた共同設計のための実測基盤という位置づけ
  - 出典: [arXiv:2610.05062](https://arxiv.org/abs/2610.05062)

- **VLA 後訓練のデータ拡張は「Critic だけ」に効かせる**（分類: 論文, 2026-10-05）
  - RL による後訓練は頑健性に効くが伸びしろが残る、という前提で画像拡張の効かせ方を系統的に検証した実務寄りの研究
  - 結論は明快で、**RL 更新時に拡張するのは critic のみ**。actor の入力はロールアウト中も更新時もクリーンに保つ。この配置で LIBERO-Plus の OOD 成功率が π0.5 で **+7.8pt**、GR00T N1.5 で **+10.0pt**
  - 逆に **actor 側を拡張すると学習が完全に崩壊**する。拡張の種類と強度も幅広く比較し、実践的な推奨をまとめている
  - 9/29 掲載の「RL は VLA のどこを書き換えているか」がパラメータ空間の解剖だったのに対し、こちらは同じ後訓練を**レシピ側から詰める**内容
  - 出典: [arXiv:2610.05994](https://arxiv.org/abs/2610.05994)

- **SuperCLUE「具身脳」評価（EmbodiedCLUE-VLA）9月版: GPT-6 Astra が首位、差は計画能力に集中**（分類: 業界動向, 2026-10-05 報道）
  - 画像＋中国語プロンプトで入出力形式を固定し、基礎知覚・視覚推論・インタラクション／計画・具身安全の4領域を judge モデルとルールベースで採点する「ロボットの脳」ベンチ。国内外10モデル（うち5つは10B以下）を評価
  - 総合は GPT-6 Astra 86.75、Gemini-3.8-Flash 82.12、Qwen3.8-Max-0902 と Nebula-EmbodiedBrain が 77.48、Gemini-Robotics-ER-2-Preview 70.86、MiMo-Embodied-7B 56.95
  - 注目は内訳で、**インタラクション／計画では Astra 85.71 対 Gemini-3.8-Flash 64.29 と 21.42pt 差**。総合の差（4.63pt）をはるかに上回り、「総合スコアは特定能力の弱さを覆い隠す」ことを示した
  - ただし測っているのは認知能力であってタスク成功ではなく、SuperCLUE 自身も「標準化されたプロトコルは専用モデルの実力を過小評価しうる」と留保している
  - 出典: [Humanoids Daily](https://www.humanoidsdaily.com/news/superclue-september-2026-robot-brain-planning-gap)
