## VLA (Vision-Language-Action) 関連ニュース — 2026-10-17

- **接触面を「グリッパの先」から広げる2本 — Whole-Body Dexterity と Uni-PNP**（分類: 論文, 2026-10-15）
  - 共通の問題意識は、現行の器用操作が**エンドエフェクタでの単純な把持に閉じている**こと。人間は腕や胴で支えたり滑らせたりするし、掴めない物は押して姿勢を作ってから掴む
  - **Whole-Body Dexterity (WBD)** は胴体や腕を**接触面として使う**全身把持を扱う。実行可能な全身把持のデータセットを生成 → 初期／目標姿勢をそこからサンプリングして any-to-any 再配置の RL エキスパートを学習 → 自己受容感覚と物体ジオメトリだけを使う単一ポリシーへ蒸留。実機 Unitree G1 にゼロショット転移し、棚から箱を片腕に抱えて机へ運んで置く長時間タスクも完遂。**完遂率 90%**（直接リターゲット 18%、汎用全身コントローラ 4%）。ただし実行中は**人の遠隔操作者が粗い動作参照で誘導する**対話運用
  - **Uni-PNP** は把持（prehensile）と非把持（non-prehensile）を**1つのポリシーで同時に学ぶ**。既存は両者を別々に作り中間目標を決め打ちして繋ぐため協調が効かず形状に敏感だった。接触で物体がどう動くかを予測する幾何エンコーダを事前学習し、**掴める物体 → 掴めない物体**の2段 RL カリキュラムを組む。既知物体 76.39%、未知物体 57.91%（最強ベースライン比 +20.52pt / +17.79pt）。倒してから掴む、掴んだまま机を使って向きを変える挙動が創発
  - 10/14 の DEFT-VLA / PRISM や 10/15 の ForceBench が「接触の**いつ・どれだけ**を効かせるか」だったのに対し、こちらは**そもそもどこで接触するか**を設計変数にしている
  - 出典: [arXiv:2610.22184](https://arxiv.org/abs/2610.22184), [arXiv:2610.21735](https://arxiv.org/abs/2610.21735)

- **Dexterity from Supervised Play: 数分の「遊び」を種に、ロボットが自分で接触データを集める**（分類: 論文, 2026-10-15）
  - 問いは「器用操作に要る接触の濃い経験を、ロボットが**自律的に**集めるにはどうするか」。タスク別デモにも sim-to-real にも頼らない道を探る
  - ①**数分の人間の遊び**を behavior cloning して play policy を作る ②自律実行で**数時間分の相互作用データ**を集め world model を学習 ③推論時は同じ play policy が MPC の候補行動列を提案し world model が評価 ④高速化のため world model 内部の self-play で閉ループの goal-conditioned ポリシーへ蒸留
  - 評価は劣駆動プッシングと多指ハンドでの **any-to-any な手中姿勢変更**。実機で hindsight behavior cloning 比 **成功率 +69.6%**、RL と同等の成功率を**相互作用データ 1/490**で達成
  - 10/13 の CASTER が「動画生成モデルにデモを作らせる」、10/11 の A Balanced Data Diet が「RL の経験配分」だったのに対し、こちらは**実機が自分で回してデータを増やす**側
  - 出典: [arXiv:2610.22340](https://arxiv.org/abs/2610.22340)

- **X-Fly: 失敗の約半分は「止まれないこと」だった**（分類: 論文, 2026-10-15）
  - 空中の vision-language navigation で VLM を毎ステップ呼ぶのは高価なので、**行動チャンクを丸ごと実行してから再計画**したい。だがデモに無い状態に入り、復帰と終了判断が崩れる
  - 診断が具体的で、OpenFly の test-seen で**失敗の 47.78% が「停止しそこねた」ケース**。到達はしているのに止まれない
  - 対策は2段。①**Recovery DAgger** で学習者が実際に訪れた状態に滑らかな復帰チャンクと停止信号をラベル付け ②**Flow-GRPO** でチャンク化 flow コントローラと**ベルヌーイ STOP ポリシー**を閉ループ結果と結果検証付きの停止監督で仕上げる
  - 1決定あたり8制御で、成功率 test-seen **74.18%** / test-unseen **51.73%**。9/25 の Rolling-WAM や 10/12 の Chronos Policy がチャンクの**時間方向の扱い**だったのに対し、こちらは**チャンクの終わり方**を正面から扱っている
  - 出典: [arXiv:2610.21450](https://arxiv.org/abs/2610.21450)

- **AA-Robotics v0.1: フロンティアモデルを実機アームで横並び採点した独立ベンチ**（分類: 業界動向, 2026-10-14）
  - Artificial Analysis によるリサーチプレビュー。各モデルに **Hiwonder NexArm（5関節＋グリッパの6軸）**と簡単な目的を与え、4台のカメラ画像を見せて**隔離コンテナから HTTP API で動作を投げさせる**。全試行ゼロショット、8つの卓上タスク、完遂100点・部分達成は進捗按分
  - 結果は **GPT-6 Astra 69.4 / GPT-6.1 Sol 64.6 / Gemini 4 Argon 55.3 / Claude Opus 5.5 48.8 / Claude Fable 5.1 46.3**
  - 最も効く数字は速度で、**人間が平均20秒のタスクにモデルは平均約30分（約100倍遅い）**。主催側も「能力は出てきたが実運用には遅すぎ高すぎる」と明記
  - 10/12 の EASG が「VLM をそのまま行動モデルにする」提案、10/14 の Gemini 4 Argon が**ベンダ自己申告**のデモだったのに対し、こちらは**同じ構図を第三者が共通条件で測った**もの
  - 出典: [Artificial Analysis](https://artificialanalysis.ai/articles/aa-robotics)

- **Nature Will、手の器用操作に全振りした 50B の「Natura-1」を発表**（分類: 製品, 2026-10-16）
  - サンフランシスコの physical AI ラボ Nature Will（CEO: Ning Ding）が、言語・画像・動画・行動を**同時に学習した 50B の Mixture-of-Experts** を公表。**100万時間超の一人称人間データ**で事前学習し、**100ms の制御ループ**で動くとする
  - 位置づけが独特で、全身制御やロコモーションを対象にせず**手の器用操作に限定**。未見物体を含む平易な自然言語指示をゼロショット実行し、長時間の連続ワークフローを自律実行できると主張
  - ただし現時点は**プレスリリースのみで、ベンチマーク・デモ映像・成功率・対応ハードウェア・提供時期・価格・資金調達のいずれも非開示**。検証材料は何もない
  - 10/15 の π API、10/16 の NEURA Neuron AI と並べると、**「どの部位・どのデータで差をつけるか」の賭け方が各社で割れている**のが見える
  - 出典: [openPR](https://www.openpr.com/news/4664302/physical-ai-lab-nature-will-unveils-natura-1-first-general), [Forbes](https://www.forbes.com/sites/johnkoetsier/2026/10/13/startup-releases-50-billion-parameter-physical-general-foundation-model-for-instant-robot-intelligence/)
