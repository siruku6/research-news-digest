## VLA (Vision-Language-Action) 関連ニュース — 2026-10-27

- **判定器は言葉で揺らぐ、だから判定器を公開物にする — Execution Logs Sway VLM Judges と RoboJev**（分類: 論文, 2026-10-24〜25）
  - 共通の土俵は、ロボット映像を VLM に採点させるという今や標準の運用。片方は**その採点が壊れる経路**を突き、もう片方は**採点器そのものを検証可能な公開物として出す**
  - **Execution Logs Sway VLM Judges** が短く鋭い。**進捗を失っている**クリップに「ロボットは進捗している」という**ログ行を1行添えるだけ**で、Gemini・Qwen・GPT の判定が中立行と比べて **10〜35pt 多く「進捗」へ反転**する。しかも**「このログは誤りかもしれない」という警告を1行足すだけで大半が消える**。偽の "task complete" は **Qwen の正答の半分を反転**させる一方、Gemini には検出可能な影響がない。モデル間で脆さが揃っていない点がむしろ怖い
  - **RoboJev** は逆方向。JEV-27B-VL を**言語モデル側のみ rank-32 LoRA**（視覚エンコーダは凍結）で 52,598 エピソード記録に適応させた**オープンウェイトの成功判定器**。研究データにだけ効く source-specific KL ペナルティで元モデルから離れすぎないよう固定し、**1回の順伝播で成功/失敗確率を出す校正済み2トークン読み出し**を使う
  - 数字は、同一機種（SO-101）の held-out 268 エピソードで**均衡精度 95.2% / AUROC 0.993**、**未見のラボ・ロボット**で AUROC 0.890。**H100 単体で 1 エピソード 0.26 秒、1,000 判定あたり約 0.19 ドル**。加えて **20,628 件の予測を 29 の model/protocol エントリに整理して公開**（API 系フロンティア VLM との比較は入力フレーム数が揃っておらず厳密な like-for-like ではないと自ら注記）
  - 10/20 の Coverage Shift が「ポリシーが上手くなると判定器の有効性が動く」だったのに対し、こちらは**判定器が傍らのテキストで動く**側と、**判定器を監査可能な成果物にする**側
  - 出典: [arXiv:2610.34151](https://arxiv.org/abs/2610.34151), [arXiv:2610.33718](https://arxiv.org/abs/2610.33718)

- **世界モデルは結局、何を買っているのか — 3本の統制実験**（分類: 論文, 2026-10-24〜26）
  - **What Does World Modeling Actually Improve?** は、FastWAM と OpenWAM の内部で**アーキ・初期化・データ・学習ステップを固定したまま、将来動画予測損失だけを抜き差し**する。既知タスク・クリーン条件では **+24.38pt / +72.91pt**。ただし**分布シフト下では一貫して残らず**、環境ランダム化ではどちらも低成功率で予測監督の優位が出ない。加えて**学習時だけ使う軽量 Transformer 予測器**を π₀.₅ の補助目的に足すと **82.94% → 89.19%**。利得の取得に**巨大な video DiT は必須でない**
  - **WorldFailBench** は「成功/失敗を当てたか」ではなく「**どう失敗するかを忠実に再現したか**」を問う。失敗理由・失敗段階・**失敗境界**の3課題で、LIBERO・RoboTwin と G1 実機を対象に**7つの世界モデル**を測り、いずれにも大きな隔たりを報告。失敗の誤表現は**弱点を誤診させ、小さなシーン変化で崩れるのに配備可能に見せる**
  - **Video World Models Need Predictable Latents** は設計側の処方。時間的目的関数と**過去条件付きデコーダ**で、同じ学習予算で**推論が最大5倍安く、学習が7倍以上速く、OOD・長ホライズンの誤差が 15〜24% 低下**。**VLM に成功判定させたときの実世界評価との一致も改善**する
  - 10/23 の DRILL（目的関数）、10/25 の DeXplicit（表現の順序）に対し、こちらは**何が買えて何が買えないのかの決算**
  - 出典: [arXiv:2610.34593](https://arxiv.org/abs/2610.34593), [arXiv:2610.33565](https://arxiv.org/abs/2610.33565), [arXiv:2610.34663](https://arxiv.org/abs/2610.34663)

- **VLA-HWBench: 遅延の内訳を7段階に割ると、効いているのはモデルサイズではなかった**（分類: 論文, 2026-10-26）
  - **18 の公開 VLA** を公式／代替バックエンド込みで **Jetson AGX Thor と AMD Ryzen AI Max+ PRO 395** 上で測り、推論を**7段階**に分解する
  - **行動生成戦略がモデルサイズより効き**、Jetson の19構成中14を支配。遅延は **Jetson で 82倍、AMD で 157倍**開き、**パラメータ数が説明する分散は最大 15%**。**少数の flow-matching ステップで長い行動チャンク**を出すモデルは制御に追随し、**トークン逐次デコードは追随しない**
  - **4bit 重み＋カーネル融合**が最も効く（π₀.₅ と GR00T N1.7 で torch.compile 比 2.6〜2.9倍）**が、存在するのはこの2モデル・Jetson 上だけ**。しかも最適化は**最も短縮できない段階へ時間を移す**（GR00T N1.7 の CPU 前処理が 12% → 39%）。最適化後にメモリ帯域が効くのは**トークン数の少ない段階だけ**で、残りはソフトウェア側の制約
  - 10/24 の韓国 K-On-Device が「制御周期 50Hz を根拠にクラウドを排除する」政策側の賭けだったのに対し、こちらは**そのエッジ予算が実際どこへ消えているか**の実測
  - 出典: [arXiv:2610.34717](https://arxiv.org/abs/2610.34717)

- **フロンティアの天井と、その使い方 — PhysLadder / EBench / ZAP**（分類: 論文, 2026-10-25〜26）
  - **PhysLadder** は16の家庭タスクを**累積3段階**（接触選択と幾何整合 L1 / 持続接触中の力調整 L2 / 接触組み替えと力調整の協調 L3）に並べ、**物理的にも視覚的にも対応づけたシミュと実機**で測る。GPT-6 Astra の実機成功率は **80.0% → 47.6% → 0.0%**。注目は忠実度で、**16タスク中10が両環境で成功数完全一致、残り6も3試行中1の差**
  - **EBench** は GPT-6-Astra を後訓練済みポリシーと**同一観測プロトコル**で繋ぎ、direct control と harness with policy を比較。前者は**短ホライズンで先行し汎化軸ごとの振れ幅が最小**な一方**長ホライズン・卓上・高精度接触で劣る**。ハーネスは**最強の後訓練済み水準まで引き上げつつトークンコストを大幅削減**するが単独構成要素の上限には届かず、原因を**呼び出し判断の非最適・サブゴール無しの固定指示・制御復帰時の把持の乱れ**と特定
  - **ZAP** は逆に安く済ませる側。27B の既製 VLM に、**実ロボットデータを一切使わず**ツールハーネス＋シミュの SFT と GRPO だけで実機 **96.7%**、GPT-6 Astra と同水準で**3倍速く17倍安い**（MolmoAct2 VLA は 33.3%）。未見の単腕 Franka でも RoboLab-120 **55.9%**
  - 10/19 HexaShell・10/20 Bitter Lesson に対し、**天井の形**・**天井の使い方**・**天井を安く再現する手**の3点セット
  - 出典: [arXiv:2610.34527](https://arxiv.org/abs/2610.34527), [arXiv:2610.35832](https://arxiv.org/abs/2610.35832), [arXiv:2610.35817](https://arxiv.org/abs/2610.35817)

- **行動表現の事前学習を、独立したスケール軸として切り出す — RynnVLA-Latent と ARPG**（分類: 製品 / 論文, 2026-10-25）
  - 共通の診断は、**限られたデモで「行動表現」と「タスク条件付き行動分布」を同時に学ばされている**こと
  - **RynnVLA-Latent**（Alibaba DAMO ほか）の **RynnLAM** は、残差的な将来特徴予測・**カメラ補正済み 3D フロー監督**・カメラ運動の分離で、見た目でなく**制御に関係する運動**を捉える潜在行動を学ぶ。**30.1K 時間**から **7億4,552万の潜在行動記述子**を生成。4B ポリシーで **LIBERO 98.8%**、**ベンチ固有の適応なしに LIBERO-Plus 84.7%**、**RoboTwin 2.0 双腕 88.6%**。**コードは Apache-2.0、2B/4B を HF と ModelScope に公開**——ただし重みは**Stage-1 の事前学習エクスポートであって閉ループ制御ポリシーではない**と明記
  - **ARPG** は分離を徹底。人間操作データで行動表現エンコーダを事前学習して**凍結**し、**130M の小さな生成バックボーン**だけがタスク条件付き分布を学ぶ。**双腕器用操作で π₀.₅ の 10.1% → 44.7%**。人間挙動の被覆を広げるほど下流性能が上がる
  - 10/24 の SkeLAM が「潜在行動から混在を剥がす」だったのに対し、こちらは**剥がした表現をそのまま規模で押す**側
  - 出典: [arXiv:2610.34356](https://arxiv.org/abs/2610.34356), [GitHub](https://github.com/alibaba-damo-academy/RynnVLA-Latent), [arXiv:2610.34453](https://arxiv.org/abs/2610.34453)
