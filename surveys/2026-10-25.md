## VLA (Vision-Language-Action) 関連ニュース — 2026-10-25

- **ポリシーの外側（ハーネス）を設計する2本 — FastHarness と HiSTEVE 1.0**（分類: 論文, 2026-10-22）
  - 共通の構図は、**ポリシーは凍結したまま、その周りの「いつ確認し、どう復帰し、完了をどう判定するか」を学習・設計の対象にする**こと。片方はコスト、もう片方は開放世界での自律性に向かう
  - **FastHarness** の問題設定が実務的で、エージェント型ロボットは失敗検知のために**毎アクションチャンクを上位モデルに点検させる**が、見慣れた状況でもコストを払い続ける。提案は π0.5 に対する GPT-6 Astra の監督を**適応的にスケジュール**するハーネス。段階記憶と点検済みの結果を使う fast path が**経験の蓄積につれて点検頻度を下げ**、相補的な recovery path が誤り訂正に監督を集中させる。復帰が検証されたら通常実行に戻り、失敗経験は次の介入判断に残す
  - 数字が効く。シミュ操作4タスクで、**最初の評価エピソードから最終5エピソード平均までに点検トークンが平均 57.2% 減**、平均エピソード時間は **85.5分 → 52.0分**。それでいて成功率は GPT-as-Policy（π0.5 + GPT-6 Astra）の 80% から **97.19%** へ上がる。**追加の学習は一切なし**
  - **HiSTEVE 1.0** は舞台が Minecraft。ロボットではなく**人間と同じネイティブ UI（マウス・キーボード）を叩く VLA** を階層構成で作る。進捗追跡の構造化記憶と VLM プランナに加え、肝は **VLA ポリシーの文脈に条件づけられた完了判定器**で、外部の採点者ではなく**実行中のポリシー内部の状態から「終わったかもしれない」を出す**。異種の操作には regime 別の正規化枝とマウス移動専用の埋め込みを当てる。知識注入→模倣学習→環境フィードバックによる RL。**MineStudio Bench 85.0%、OpenHA 平均成功率 37.4%**、原材料から鉄のツルハシまで到達
  - 10/20 の Compile Once, Run Cheap が「フロンティアをオフラインの作者に限定してコストを落とす」、10/24 の CARE が「クラウドとローカルのどちらが権限を握るか」だったのに対し、こちらは**同じ監督者を使い続けたまま呼ぶ回数を経験で減らす**側と、**完了判定をポリシーの内側から取る**側
  - 出典: [arXiv:2610.31427](https://arxiv.org/abs/2610.31427), [arXiv:2610.31162](https://arxiv.org/abs/2610.31162)

- **Learning Robot Behavior Priors from Non-Robotic Synthetic Data: 身体を持たないデータだけで、どこまで事前分布が作れるか**（分類: 論文, 2026-10-22）
  - 問いが挑発的で、実ロボットデータがボトルネックだという前提に対し、**身体性を一切持たないデータから必要な構造をどこまで獲得できるか**を測りにいく。検証は**ロボット行動予測**という、事前学習目的としても転移テストとしても自然な一点に絞る
  - **ロボット制御の数学的抽象を模した手続き生成パイプラインを3種**作り、Transformer の事前学習に使う。実世界の挙動を一度も見ていないモデルが、**未知の実機タスクで非自明なゼロショット予測性能**に達し、しかもその経路は **in-context learning** である点を示す。汎用の因果的事前分布より、**制御に特化した事前分布の方が明確に強い**
  - 誠実なのは比較の出し方で、**計算量を揃えた実ロボットデータのベースラインには負ける。ただし負けるのは、そのベースラインが学習したデータセット上だけ**。高価な実データ収集を置き換えるのではなく**補完する**、という結論に留めている
  - 10/24 の Figure（クラウドソースで 3,750万本の人間動画を積む）と AgiBot（判断ロジックを注釈として構造化する）が**どちらも実世界の映像を仕入れる競争**だったのに対し、こちらは**仕入れずに手続き生成で作る**という第3の選択肢にあたる
  - 出典: [arXiv:2610.31275](https://arxiv.org/abs/2610.31275)

- **DeXplicit: ピクセルを作る前に、メートル単位の3次元で世界を動かす**（分類: 論文, 2026-10-22）
  - 既存の操作用世界モデルは、**行動条件付きダイナミクス・カメラ運動・見た目の合成を動画生成モデルの中で一緒くたに**するか、物体構造を持たない点軌跡として表すかのどちらかだった、という整理から始まる
  - 提案は順序の入れ替え。初期シーンと将来の手の軌跡を与えると、**軽量な3Dダイナミクスネットが物体中心の運動と変形をメートル空間で予測**し、その上で見た目を**予測した3D運動に沿って輸送して将来視点へ射影**する。描画側は物理を学ぶ必要がなくなり、**不確かな領域と新たに見えた領域の穴埋めに専念**できる
  - 副作用として効率が出る。生成履歴に条件づけながら**ブロックあたり2ステップのデノイズ**で済み、自社の 14B 双方向構成比で動画合成が **57倍高速**。精度も HOT3D / OakInk2 / PhysTwin で **PointWorld 比 moved-point 誤差 −27〜40%**、同一レンダラ下の HOT3D で物体忠実度 IoU+ **+47%**
  - 10/23 の DRILL が「世界モデルの**目的関数**をピクセルからポリシー勾配へ入れ替える」だったのに対し、こちらは**目的関数ではなく表現の順序**を入れ替えている。10/23 の UniFlowWAM がシーンフローを第3のモダリティに昇格させたのと並べると、**幾何をどの段階で明示するか**の選択肢が揃ってきた
  - 出典: [arXiv:2610.30781](https://arxiv.org/abs/2610.30781)

- **GelSlim 5.0: 指先のカメラ1台に、外界の視覚と接触の触覚を同居させる**（分類: 論文, 2026-10-22）
  - 出発点は、視覚と触覚は相補的なのに**接触点こそ外部カメラから遮蔽される**という構造的な噛み合わせの悪さ。素直な解は指先にカメラを足すことだが、今度はカメラ間の外部パラメータ校正が要る
  - 解き方が巧みで、**固定カメラ1台と連続した UV 応答性の接触層**を組み合わせ、**照明を切り替えるだけで同一視点から膜越しの視覚画像と接触の触覚画像を交互に取得**する。カメラ間校正という工程そのものが消える
  - 融合側は **VisTacFusion**。平面上の物体姿勢と接触形状に**別々の予測経路**を置き、非対称なボトルネック融合で**視覚の文脈を入れつつ、深度と法線の推定に要る触覚の空間特徴を潰さない**。modality dropout により**どちらか片方だけでも推論できる**
  - 実機12物体の検証で、同一モデルの**触覚のみ推論に対し**、両方を与えると深度 MSE **−61.2%**・角度誤差 **−72.3%**・並進 L₁ **−61.3%**。**視覚のみ推論に対しては**深度 MSE **−93.7%** と大きい一方、角度 −6.1%・並進 −8.6% に留まり、**何が触覚でしか取れないのかが数字で分離**されている
  - 10/24 の OpenTac と VecTile が「**せん断を安く・好きな形で取れるようにする**」方向だったのに対し、こちらは**センサの個数そのものを1台に畳んで校正工程を消す**方向
  - 出典: [arXiv:2610.31334](https://arxiv.org/abs/2610.31334)

- **DEEP Robotics が「脳」を5本立てで公開 — 四足の巡回走行データを土台に据える**（分類: 業界動向, 2026-10-24）
  - 杭州の四足ロボット企業が、具身知能アーキテクチャ **DEEPRobotics-Brain** を支える5要素を同時発表。MIT・UCSD・UIUC・清華・浙江大・HKUST・北京理工との共同研究として出している
  - **DR-WM-1.0** は見た目のもっともらしさと物理的実行可能性は別物だという立場で、シーン幾何に**摩擦・粗さ・剛性の密な物理事前分布**を重ねる。dual-ControlNet で幾何とカメラ運動に条件づけ、ロボットとコントローラの状態を保った自己回帰ロールアウトを回す。**258万の画像-マスク対と10万本超の実機クリップ**。例示は変電所点検で、**危険な近道と遠回りの安全経路を事前に比較させる**
  - **DR-VLA-2.0** は航法と操作の二本立て。航法側 **EgoLynx** は意味・空間・関係を束ねたドメイン不変表現と Mixture-of-Transformers 構成で、**厳選した一人称動画1万時間＋遠隔操作2,000クリップ**。四足航法スコア 約+5%、開ループの方位誤差 **−14.6%**。操作側は**片腕あたり13個の解釈可能な「運動アトム」**を座標として定義し、力フィードバックを織り込む。未知レイアウトでのタスク進捗 **87.8%**、引き出し＋プラグ 78.5%、花瓶拭き 75.2%
  - **DR-APO** は方策改善を方策表現から切り離し、Gaussian・拡散・flow matching を同じ枠で後訓練する（尤度の明示評価が不要）。MuJoCo-v5 で**拡散10比較中9、flow は10比較すべてで最良**。実機 LYNX M20 の航法後訓練はシミュ 70.33% → **89.55%**、実世界 25% → **65%**。**DR-Agent** は時刻付き4D信念と predict-observe-replan で**環境が変わった後の古い空間記憶を更新**する（EvoWorld-Bench は54シーン・803,680タスク事例・約23.9万件の動的変化）。**DR-Benchmark** の LynxScenes は**833.6時間・3,294.7km の実走行**、約10万航法クリップ・300万注釈フレームで、25モデルを4タスクで横並び評価
  - 留保は明確で、**各要素はプレプリント参照に留まり詳細は開発者センター送り**。多くのベンチで比較対象の内訳が薄く、**推論遅延と計算要件は非開示**。それでも位置づけは鮮明で、10/24 の Figure（人間動画を量で積む）と AgiBot（判断の根拠を注釈する）に対し、こちらは**自社の実機が街路と構内を走って貯めた航法ログ**を土台に据える第3の賭けにあたる
  - 出典: [GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/24/3387678/0/en/deep-robotics-unveils-five-research-advances-in-embodied-ai.html), [Manila Times](https://www.manilatimes.net/2026/10/24/tmt-newswire/globenewswire/deep-robotics-unveils-five-research-advances-in-embodied-ai/2453278)

その他、**FETA**（VLN の test-time adaptation で、軌跡単位に一様な人間フィードバックを当てる無駄を突く。正規化方策エントロピーの変動が大きい軌跡を絞り、**その中の critical action 1つだけにエントロピー勾配顕著性で二値フィードバックを求め**、その手のみを更新。少ない介入で SOTA, [arXiv:2610.30643](https://arxiv.org/abs/2610.30643)）、**SCOPE**（TAMP データセット生成で、**プランナの実行失敗を信号にシーングラフ側の論理矛盾を遡って訂正する**。PDDL ベースの DELTA 比 成功率 +12.33%, [arXiv:2610.31518](https://arxiv.org/abs/2610.31518)）、**PiHand**（手-物体相互作用の潜在事前分布を物理ベース方策学習へ, [arXiv:2610.31299](https://arxiv.org/abs/2610.31299)）、**Tactile-Based Robotic Manipulation**（力学駆動からデータ駆動までの触覚操作サーベイ。模倣学習・RL・VLA・予測モデルを横断, [arXiv:2610.30438](https://arxiv.org/abs/2610.30438)）も候補でしたが、分量の都合で見送りました。
