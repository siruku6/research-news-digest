## VLA (Vision-Language-Action) 関連ニュース — 2026-10-31

- **比較実験の前提が結論を作っている2本 — Same Label, Different Interface と CuraEval**（分類: 論文, 10/28）
  - **Same Label, Different Interface** は「position 制御 vs velocity 制御」という比較が**ラベルだけでは実験条件を定義できていない**と突く。接触の濃い Factory 3タスクで5インタフェース×10シードを比較し、**同じ位置フィードバック則のまま物理スケールだけ差し替えると成功率の標本中央値が 0.645〜1.000 動く**。生トルク指令ゲインを厳密に一致させた速度インタフェースでも差が残り、**「位置と速度は等価」は示せない**
  - **CuraEval** はデモ選別側。PSD スコアは**エピソード長と位置の二乗ノルムだけで決まり、単なるエピソード長とほぼ同順位（ρ=0.999）**。短い 50% 採択は 70.7% → 76.5% だが、**幾何エントロピー LOO 選別は can で 94.7% → 74.0% とランダムを下回る**
  - 痛いのは再現性で、**旧プロトコルで 76.7% → 86.7% の改善に見える条件が、チェックポイント報告・ロールアウト数・評価シードを揃え直すと 80.5% → 79.5% に反転**。**Holm 補正後に全データ学習を有意に上回る選別条件はゼロ**
  - 出典: [arXiv:2610.38104](https://arxiv.org/abs/2610.38104), [arXiv:2610.38221](https://arxiv.org/abs/2610.38221)

- **人間の手から何を持ってくるか — TouchBridge と EgoContact**（分類: 論文, 10/29）
  - **TouchBridge** の **Tac-Retarget** は**実測した接触を条件に指先の接触パッチと空間関係を手の内・手の間で揃える**。**3D 物体モデル・姿勢推定・物理シミュのいずれも不要**。実機 **72.5%**（直接ロボットデモ同数は 77.5%）だが**収集時間は 7分の1**
  - **EgoContact** は一人称動画を事前学習材料ではなく**検証の道具**に。**手検証済み 22.5K 件**に接触前観測・意図・ピクセル精度の接触位置を付す。既存 affordance 転移方策のメモリバンクに差すだけで把持成功がシミュ **14.2% → 31.2%**、実機 **16% → 58%**
  - 出典: [arXiv:2610.40349](https://arxiv.org/abs/2610.40349), [arXiv:2610.39167](https://arxiv.org/abs/2610.39167)

- **事前学習の「単位」を言語に揃える2本 — RoboAtom と Language-Grounded F/T Pretraining**（分類: 論文, 10/29）
  - **RoboAtom** は **145万軌跡・16,000時間超**に統一原子行動注釈を付け、スキル認識と時間境界検出の **RoboAtom-Bench** を併設。データ・ベンチ・モデル・パイプラインを公開予定
  - **Language-Grounded F/T** は**両腕6軸 F/T 履歴を凍結言語空間へ整列**。未知物体でもテキストプロトタイプで行動・重量・把持相互作用を読み出し、実機では**エンコーダ更新なしのラベル無し校正だけで接触と支持状態を認識**。事前学習に無いコネクタ挿入も LoRA で効率的に獲得
  - 出典: [arXiv:2610.40207](https://arxiv.org/abs/2610.40207), [arXiv:2610.39314](https://arxiv.org/abs/2610.39314)

- **SpaceAct: 計画を渡しても埋まらない、3D グラウンディングという底**（分類: 論文, 10/28）
  - **特権座標なし**で 36 タスク族・108 検証済みインスタンスを閉ループ行動と能動的知覚で測る。カメラを回して遮蔽を解き、シーン内の定規を読み、掃引衝突と静力学の検査下で 6-DoF 姿勢を出す
  - フロンティア MLLM 10種の最難 44 件で**スコア 4.8〜79.1、7モデルは 6-DoF タスクの 27.3% 以下**。上位3モデルは **+plan で差の 44% しか埋まらず衝突 5.2 件/エピソード、+state では 90% が埋まり衝突 0.5 件**。**失敗の 46% は衝突ループか観測ループ**
  - 読みは明快で、詰まっているのは**計画ではなく 3D 視覚グラウンディングと行動の精緻化**
  - 出典: [arXiv:2610.38405](https://arxiv.org/abs/2610.38405)

- **配備コストをどちらから削るか — GO-3 の実地学習の数字と Bleu Robotics の €5M**（分類: 業界動向, 10/29〜30）
  - 10/30 掲載分の続報として、**未公開だった GO-3 Preview の性能値**が出た。実店舗に G2 を置いた検証で**初日 28.6% → 5日後 85.7%**、フック掛けは**通常の教師ありファインチューン比 +17.7pt**、卓上カーリングは**オンライン練習4時間で被験者平均超え**。ただし**85.7% の対象タスク集合・学習データ規模・計算要件は非公開**
  - **Bleu Robotics**（パリ、€5M プレシード、INRIA 出身2名＋元ルノー製造マネージャが 2025 年創業）は逆向きの賭け。**アブダクティブ学習で操作者デモ10本程度**、**ノートPCで2分未満の学習、導入から1時間以内に稼働**を狙い、**産業安全に要る説明可能性と 99%以上の精度**を両立すると主張。**ベンチマークも第三者検証も非公開**で、手法の中身も未開示
  - 出典: [Interesting Engineering](https://interestingengineering.com/ai-robotics/humanoid-robot-achieves-success-with-agibot-go3), [EU-Startups](https://www.eu-startups.com/2026/10/french-startup-bleu-robotics-secures-e5-million-to-teach-humanoid-robots-new-tasks-with-fewer-demonstrations)
