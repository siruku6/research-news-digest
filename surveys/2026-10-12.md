## VLA (Vision-Language-Action) 関連ニュース — 2026-10-12

- **RESCUE: 「そのアラームは従う価値があるのか」を反実仮想で測る**（分類: 論文, 2026-10-09）
  - 実行時の失敗モニタは従来「失敗と成功をどれだけ正確に分けるか」で評価されてきた。だが**正確でも復帰に間に合わなければ無意味で、不要な介入は成功したはずの実行を壊す**という問題提起
  - シミュレータとポリシーの状態をチェックポイントで復元し、代替行動を比較して**復帰条件を満たす最後のチェックポイント**を特定。アラームに従うことがタスク完了コストを下げるかを直接評価する。OpenVLA-OFT と π0.5 × LIBERO-Spatial / LIBERO-Plus で **128,340 本の反実仮想分岐**を実行
  - 復帰可能性は「ロボットの状態」ではなく**状態と介入手段の組**で決まる。τ=0.5 の OpenVLA-OFT/LIBERO-Plus では、継続のみなら 66 失敗中 14 件が復帰可能、継続＋スクリプト復帰なら 34 件。条件によっては復帰動作がかえって復帰可能性を下げる
  - 最も効く数字は、stop-and-reset 前提では**理想的な検知器でも誤報率 2.0〜3.3% を超えると不要なリセットの損が早期停止の利得を上回る**こと。10/03 の TRUST や 10/05 の SocialVLA が「どう検知するか」だったのに対し、こちらは**検知器の良し悪しを測る物差し自体**を問い直している
  - 出典: [arXiv:2610.13516](https://arxiv.org/abs/2610.13516)

- **EASG: アクション空間を観測に「描き込む」だけで、VLM がそのまま行動モデルになる**（分類: 論文, 2026-10-09）
  - 既存 VLA は行動トークン・行動ヘッド・アクションエキスパートを導入するが、**その意味はロボットデータの事前学習で学ぶしかない**。一方モジュール型の基盤モデル手法は VLM の能力を活かせるが、外部の計画・制御足場に依存し end-to-end で学習できない
  - EASG は **TCP（ツール先端）中心のアクションフレームを手首カメラ画像に投影**し、行動を VLM のネイティブなテキスト生成インタフェースで表現する。これで連続行動空間の意味が VLM の知覚文脈に直接見える状態になり、**ロボット行動の事前学習も追加モジュールもなしに**実行可能な行動を生成できる
  - 物体位置・カテゴリ・ロボット身体をまたいだゼロショット操作が成立し、同じインタフェースのままロボット軌跡でのファインチューンも可能（解放された能力の上にさらに積める）
  - 10/11 の SpatialHarness が「凍結モデルの外側で足りない視点を作る」、10/10 の Embodied Turing Machines が「モデルを制御ループから外す」だったのに対し、こちらは**行動インタフェースの設計だけで VLM を中に残す**第三の立場
  - 出典: [arXiv:2610.12832](https://arxiv.org/abs/2610.12832)

- **Splat2Act: スマホスキャンだけで、汎用ポリシーを「その人の部屋」に個別最適化する**（分類: 論文, 2026-10-09）
  - 出発点の数字が強烈で、**π0.5 は実際にスキャンした配備シーンでは無適応だと把持成功率 0%**。かといってユーザごとに実機デモを集めるのは非現実的、という問題設定
  - 手持ちスマホのスキャンと所有物体の画像だけを人手入力とし、3D Gaussian Splatting で衝突形状付きのデジタルツインを構築。**卓上／非卓上の置き場を自動発見**して実行可能な把持タスクを生成し、特権情報付きシミュレータで成功デモを作る。先行の real-to-sim が単一卓上の再構成だったのに対し、**建物スケールの屋内環境**を対象にする点が差
  - 可航面積 中央値 104.87 m²・置き場7個のキャンパス環境 **101件**に適用し、852 の置き場と **68,000 件超**のデモを生成。公開物体資産への適応（Stage 1）→ ユーザ所有物体への個別化（Stage 2）の2段で π0.5 をファインチューン
  - 対象シーンで把持成功率 **62.5%**、実機 Stretch 3 の12タスク部分集合で **63.9%**（同条件のシミュ 66.7% とよく一致）。10/10 の SimVLA が「完全合成で汎用に転移」だったのに対し、こちらは**合成データで個別環境に寄せる**方向
  - 出典: [arXiv:2610.13945](https://arxiv.org/abs/2610.13945)

- **Odyssey-3: world model 製品側から「VLA ベースラインを上回った」と主張**（分類: 製品, 2026-10-08 公開・研究プレビュー開放）
  - プロンプトから対話可能な環境を生成し、行動や外部イベントに応じた変化をリアルタイム予測する基盤 world model。自己回帰拡散 Transformer で、蒸留版がブラウザ上の無料リアルタイムプレビューを支える
  - **Physics-IQ Verified の video-to-video で 66.1**（公表値として最高、image-to-video は 54.7）。流体・光学・固体力学・磁性・熱力学をまたぐ評価
  - ロボット応用の主張が3点。①アームは**数十時間のデモ**でタスクを完遂し、デモに存在しない把持失敗後のグリッパ再配向のような復帰挙動を示した ②Flexion が本モデル上に構築したヒューマノイド制御ポリシーが、**環境変化・照明変化の下で検証対象の VLA ベースラインを上回った** ③インドの実道路の運転方策を**バックボーン凍結・20時間のデータ**で学習
  - ただし比較対象の VLA が何か、試行回数、評価プロトコルはいずれも非公開で、限界の明示もない自己申告。9月以降「VLA か world model か」という議論が論文側で続いていたのに対し、**製品側が直接 VLA との優劣を主張した**という点で位置づけが変わる
  - 出典: [Odyssey](https://odyssey.systems/meet-odyssey-3), [The Next Web](https://thenextweb.com/news/odyssey-3-world-model-robots-humanoids-cars-drones)

その他、単体では新規性のある **JitterVLA**（VLA の疎な目標指令が遅延・不規則に届くため、妥当な予測行動でも人の近くで急峻な動きになる問題。同一の指令列と到達タイムスタンプを別のコントローラに再生して**コントローラの寄与だけを切り出す**。3種の公開 VLA・838エピソード・実機 UR3 で、補間により 200ms 遅延時の p99 ジャークを 615 → 106 m/s³（−83%）、追従誤差は 2.0cm 増, [arXiv:2610.13628](https://arxiv.org/abs/2610.13628)）、**Chronos Policy**（観測取得時刻と行動実行時刻を明示的に条件に入れ、time-aware RoPE で物理時間に注意を依存させる。観測レートや推論レイテンシが変動しても崩れず、非同期・マルチレートのデータから学習できる。10/08 の RoboPace が「動作の時間配分の再設計」だったのに対し、こちらは**時間をポリシー入力に昇格させる**側, [arXiv:2610.13929](https://arxiv.org/abs/2610.13929)）、**Forward Dynamics Models**（未来予測を**行動特徴で条件づける**（逆ではない）ことで、真の未来状態が行動を教師できる一方で予測誤差は行動に伝播せず、推論時は未来生成を丸ごと飛ばせる。LIBERO 平均 99.4%, [arXiv:2610.13117](https://arxiv.org/abs/2610.13117)）、**Spa-Bench**（SO-101 実機での空間グラウンディング専用ベンチ。物体・動作は学習済みに保ったまま空間配置だけ OOD にすると成功率 67.5–73.3% → 40.7–52.0%、直接指示に言い換えると 28.3–40.0pt 回復。4,092エピソードを公開, [arXiv:2610.12696](https://arxiv.org/abs/2610.12696)）、**Evidence-Guided Counterfactual Learning**（tail タスクの視覚的根拠が不足すると、ポリシーがデータの多い head タスクの行動パターンに退避する現象を同定し、根拠を除去した反実仮想観測で指示-根拠-行動の結び付きを強化。追加データも領域注釈も推論時コストも不要, [arXiv:2610.12861](https://arxiv.org/abs/2610.12861)）、**AutoBio+**（炎・蒸気・気泡といった**実験中に変化する視覚条件**を制御可能に含む生物実験室の器用操作ベンチ。14タスク×4身体, [arXiv:2610.13643](https://arxiv.org/abs/2610.13643)）も候補でしたが、分量の都合で見送りました。
