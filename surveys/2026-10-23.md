## VLA (Vision-Language-Action) 関連ニュース — 2026-10-23

- **ロールアウトを回さずに「良さ」を読む2本 — Sensorimotor Alignment と Progress Probes**（分類: 論文, 2026-10-22）
  - 共通の賭けは、**モデルの内部表現だけで、閉ループ実行の代わりになる情報が取れる**こと。片方はデプロイ前のモデル選び、もう片方は実行中の監視に使う
  - **Sensorimotor Alignment (S²)** は Platonic Representation Hypothesis を身体性へ拡張する。「視覚と言語が実在の共有統計モデルへ収束するなら、**運動軌跡も同じモダリティのひとつではないか**」という問い。感覚表現が**物理運動の幾何とどれだけ整合するか**を測る**学習不要のオフライン指標**を定義し、複数のモデル族で下流タスク成功率と正の相関を示す。効くのは**VLA へファインチューンする前の VLM バックボーン選別にも使える**点で、高コストな閉ループ評価の前段フィルタになる
  - **Progress Probes (P²)** は監視側。既存のランタイム監視は**外部の VLM を別途走らせる**ため複雑でコストが高い。提案は逆で、**ポリシー自身の活性にデモから線形プローブを学習して進捗を推定**し、期待進捗から外れた実行を弾く。π0.5 でシミュ・実機とも、**VLM ベース監視や失敗データを要する手法と同等以上**
  - 10/20 の Coverage Shift が「外部判定器の有効性が学習で動く」だったのに対し、こちらは**そもそも外部判定器を置かない**方向。10/22 の Post-hoc Epistemic Uncertainty と合わせ、「監視材料は本体の中にある」という主張が3本続いている
  - 出典: [arXiv:2610.31670](https://arxiv.org/abs/2610.31670), [arXiv:2610.31613](https://arxiv.org/abs/2610.31613)

- **DRILL: 世界モデルを「ピクセル」でなく「ポリシー勾配」で訓練する**（分類: 論文, 2026-10-22）
  - VLA の RL 後訓練で実機相互作用を減らすため世界モデルが使われるが、**学習目標は依然として1ステップ先のピクセル予測**。本来の役割は想像ロールアウトから**ポリシーを良くする学習信号を出す**ことなのに、目標がずれている
  - ずれが実測値で出ているのが効く。**ピクセル MSE が低いほど悪いポリシー勾配になりうる**し、**次フレームの MSE が 17% 悪い世界モデルの方が下流のポリシーは良くなる**
  - 提案は二層最適化で、想像ロールアウト上の GRPO 更新**後**のリターンを最大化するよう世界モデルを更新する。実装は2系統で、**追加のシミュレータ実行が不要な閉形式の代理（DRILL-VWI）**と、内側更新を truncated Hessian-vector product で微分する**完全なメタ勾配（DRILL-IMG）**。前者が後者の局所1ステップ成分を復元することも示す
  - 5つの操作シミュレータ・2つの VLA バックボーンで、DRILL-IMG は **WMPO 比 +13.1pt / RLVR-World 比 +7.9pt**。RLVR 事前学習とは競合せず補完関係
  - 10/03 の Planning Limits や 10/08 の Long-WAM が「世界モデルで**どこまで計画できるか**」だったのに対し、こちらは**何を最小化すべきかという目的関数そのもの**を入れ替えている
  - 出典: [arXiv:2610.30814](https://arxiv.org/abs/2610.30814)

- **When One Step Is Enough: 1ステップ生成は、最初からタダで付いてきていた**（分類: 論文, 2026-10-22）
  - flow matching は VLA の主流だが推論時に ODE を反復求解するため制御周波数が頭打ちになる。そこで単発生成のための蒸留や補助目的が次々提案されてきた。本稿の問いは身も蓋もなく「**それは本当に必要か**」
  - **6つの flow matching VLA** を調べると、規模のある領域では**1ステップ生成が多ステップサンプリングとほぼ一致**し、多ステップ積分の利得は一貫しない。条件は**十分に学習され、十分な容量がある**こと
  - 実務上の含意が明快で、大きな VLA では**再学習も蒸留も補助目的もなしに、多ステップモデルからそのまま単発ポリシーが取れる**。低遅延配備のためだけに別手法を足す理由が消える
  - 10/06 の Beyond LLM Serving や 9/25 の Rolling-WAM が「**どう速くするか**」の提案側だったのに対し、こちらは**その提案群の前提を崩す**否定的結果
  - 出典: [arXiv:2610.30735](https://arxiv.org/abs/2610.30735)

- **AQUAACT: 水中では、陸で事前学習した大きな VLA が小さなスクラッチ学習に勝てない**（分類: 論文, 2026-10-18）
  - 水中作業は今も人間パイロットの手動操縦が主で、VLA を据える動機はある。ただし**学習データが決定的に足りない**。着眼は現場の操作形態そのもので、**パイロットがカメラ映像を見てジョイスティックを操る**構図をそのまま記録対象にする
  - 公開されたのは**カメラ画像と人間のジョイスティック指令を言語注釈付きで対応させた初の水中データセット**。実環境 **1.9時間**＋シミュ **17.9時間**（いずれも人間パイロットが操縦）に慣性計測を同梱。シミュのデモが実データへ転移し、**必要な実機デモ数を大きく減らす**
  - 閉ループベンチの結果が厳しい。模倣学習ベースラインから VLA まで**7ポリシーを各々の既定レシピで学習しても、どれもエピソードの1/5すら完遂できない**
  - 最も効く所見は転移側で、**陸上データでの事前学習は、大きな VLA にスクラッチ学習の小さなポリシーに対する優位を与えない**。10/16 の月面ローバ VLA が「未知擾乱下での実行ホライズン」だったのに対し、こちらは**陸上で積み上げた事前分布が通用しない領域の存在**を測っている
  - 出典: [arXiv:2610.25534](https://arxiv.org/abs/2610.25534)

- **脳を自作するか、時間貸しで買うか — HD Hyundai の内製 VLA と Dream Labs の $90M**（分類: 業界動向 / 製品, 2026-10-19〜22）
  - **HD Hyundai Robotics** は 10/22、**内製 VLA 基盤モデル**で動く双腕ロボットを大邱の FIX 2026 とラスベガスの FABTECH 2026 で同時公開。GR00T や π0 をライセンスする競合と逆に、**自社の製造現場での配備そのものを学習データ源に据える**構え。脚はなく十指の双腕で、**手首の6軸力覚センサ**と指・掌の**静電容量式触覚アレイ**（Aidin Robotics と協業）を持ち、まず結束・組立、その後に溶接・フライスへ広げる。ただし**アーキテクチャ・学習データ構成・ベンチマークはいずれも非公開**で、GR00T N1.7 や π0 との比較は現状不可能
  - **Dream Labs** は 10/19、**シード $90M**（B Capital と Kindred Ventures がリード）。創業陣は元 NVIDIA の研究者で CEO は Joel Jang 氏。**Dream-1** はロボットのデモではなく**人間が日常作業をする動画**で学習し、「次に何が起きるか」を予測して行動へ変換することで**機種をまたぐ転移**を狙う。**グリッパ付きなら未見のロボットでもゼロショットで動く**と主張
  - 売り方が独特で、カメラ映像＋平易な自然言語指令を**モータ指令に変える時間課金のクラウド API**として提供する。**20社超のハードウェア提携先**、対象は 2,000〜10,000ドル帯の機体、現状は卓上のピック&プレースや洗濯物たたみ。なお**時間単価は報道間で 0.75〜3ドルと割れており**、ゼロショット転移を裏づける公開ベンチも本番配備データも出ていない
  - 並べると賭け方が正反対になる。**配備の深さでデータの輪を回す側（HD Hyundai）**と、**人間動画で先に汎化を作り機種を選ばず薄く広く売る側（Dream Labs）**。10/20 の Eka Robotics が「言語を引いて力を足す」だったのに対し、こちらは**脳の調達経路**という別軸の分岐
  - 出典: [TechTimes](https://www.techtimes.com/articles/329364/20261022/house-robot-brain-hd-hyundai-debuts-dual-arm-physical-ai-platform-its-own-model.htm), [The AI Insider](https://theaiinsider.tech/2026/10/19/dream-labs-raises-90m-in-seed-funding-to-build-foundation-models-for-any-robot/), [Forbes](https://www.forbes.com/sites/johnkoetsier/2026/10/19/robot-brains-for-75-centshour-former-nvidia-researchers-raise-90-million/)

その他、単体では新規性のある **AgenticRoboRL**（ハーネスや外部記憶ではなく**プランナ本体を後訓練**する。VLA スキル呼び出しと制御コード生成の違いをアダプタで吸収し共通 RL パイプラインへ。LIBERO-PRO で 9B プランナが **18.1% → 71.0%**、外部記憶なしで Codex (GPT-5.5)＋外部記憶の 72.1% に迫る, [arXiv:2610.28589](https://arxiv.org/abs/2610.28589)）、**Echo**（停止信号と失敗信号を**行動チャンクの2次元として行動と一緒にデノイズ**し、信号を行動より速く収束させて後段の行動生成を条件づける。フレーム単位の進捗注釈も外部監視モデルも不要, [arXiv:2610.31569](https://arxiv.org/abs/2610.31569)）、**FocusVLA**（多視点入力を入れても**ポリシーは手首視点に固執し続ける**という測定から出発し、過去行動から将来の接触意図を予測して視点ルーティングを段階適応させる。RoboTwin 2.0 で π0.5 比 **+10.10pp**、実機 71.7% → **85.0%**, [arXiv:2610.31423](https://arxiv.org/abs/2610.31423)）、**LocoManiLab**（ロコマニピュレーションの統合テストベッド。234タスク・シミュ遠隔操作 51.5時間で、**12ポリシー × 共通コントローラ**と**2ポリシー × 5コントローラ**を分離して測り、シミュと実機でポリシー順位が一致, [arXiv:2610.30876](https://arxiv.org/abs/2610.30876)）、**Co²Gen**（分散協調の計画を実行可能な関数として自動生成し、**人間の遠隔操作なしに**マルチロボット協調データを作る。人手収集データでの微調整と同等, [arXiv:2610.30671](https://arxiv.org/abs/2610.30671)）、**UniFlowWAM**（3D シーンフローを視覚・行動と**対等な第3のモダリティ**に昇格させ、10目的のロール格子で同一モデルを方策・順/逆ダイナミクス・予測器に使い分ける。実機双腕4タスクで 68.5% → **87.0%**, [arXiv:2610.30991](https://arxiv.org/abs/2610.30991)）も候補でしたが、分量の都合で見送りました。

今週の候補のうち、Measuring the Reasoning-Action Coupling（運転 VLA の推論と軌道が弱くしか結合していない）は 10/22 の Perceives but Doesn't Brake および NavBind と、Memory before Goal は 9/26 の MemBodied と、Alpha（故障注入）は 10/15 の LIBERO-RIG および 10/21 の RoboCasa-Shift と、AeroDASH は 10/17 の X-Fly と、SPAR・CondenseVLA・PaceVLA・SmolVLA-MoE は 10/06 の Beyond LLM Serving と、Agentic World Action Models (AW-0)・FRED は 10/08 の Long-WAM および 10/10 の Embodied Turing Machines と、FR-VLA は 10/15 の ForceBench と、Vision-Language-Delta-Action は 10/16 の VLA-Δ と、PLaCA は 10/16 の Rethinking Supervision Targets と、HandsOn は 10/18 の Evo-DexBench と論点が重なるため除外しました。業界側では Tesla の Optimus フリーモント生産開始（10/22、顧客出荷は2027年後半目標）、Noetix の香港 IPO 申請、元 Boston Dynamics 技術者による家庭用 Voxel（2万ドル）、Generative Bionics と AMD のイタリア訓練拠点、国内では Highlanders の基盤モデル Kepler（世界モデル＋VLA＋RL、三菱自動車 京都工場で2027年4月生産開始予定）も出ていますが、VLA の技術的論点が薄いか検証材料がないため見送りました。NVIDIA の Alpamayo 2 Super（32B 運転 VLA）は**一次発表が5月末の GTC Taipei で期間外**のため対象外です。
