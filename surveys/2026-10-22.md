## VLA (Vision-Language-Action) 関連ニュース — 2026-10-22

- **「見えているのに効いていない」を別々の場所で測る2本 — NavBind と Perceives but Doesn't Brake**（分類: 論文, 2026-10-20〜21）
  - 共通の主張は **binding gap**、つまり情報はモデルの内部にあるのに行動生成を支配していない、という断絶。片方は指示→行動、もう片方は知覚→行動で同じ穴を突く
  - **NavBind** は航法 VLA の問い。「ゴールに着いた」ことは**指示に従ったことを一切示さない**（視覚的手がかりや移動履歴だけでも着ける）。R2R-CE / RxR-CE の指示を経路単位で組み替え、**既に通った区間の記述は同一で分岐先だけが違う指示対**を **3,252 の分岐点文脈**として構成。エージェント状態と履歴を固定したまま、生成行動列・固定参照行動列の尤度・視覚アテンションの変化を比較する。結論は厳しく、**航法成功率が高いモデルほど忠実に指示に従っているとは言えない**
  - **Perceives but Doesn't Brake** は運転 VLA。反実仮想シミュと実走ログ再生で、**進路上の危険は視覚表現に確かに符号化されている**のに、縦方向の計画は**自車の速度履歴に支配され**、危険との距離にも自分の推論トレースにも弱くしか反応しないことを示す。軌道生成器はブレーキを打てるのに打たない
  - 修正が軽いのが効く。**重みを一切触らず**、凍結した Alpamayo-1.5 の flow-matching サンプラへ危険条件付きのエネルギーを注入するだけで、フットプリント侵入 **58.1% → 14.5%**、停止距離が残る限り制動が復活し、制動関連の閉ループ試験では**衝突がゼロに**
  - 10/16 の Do VLAs Really Follow Instructions? が「How-level 指示が効かない」という**入力側の話**だったのに対し、こちらは**内部に情報があることを確かめた上で、そこから行動までの経路を測る**
  - 出典: [arXiv:2610.29203](https://arxiv.org/abs/2610.29203), [arXiv:2610.28184](https://arxiv.org/abs/2610.28184)

- **VLA-Retain: カメラ条件に合わせて視覚を直すと、別の次元が壊れる**（分類: 論文, 2026-10-20）
  - 観測条件のずれに弱い VLA へ**視覚モジュールだけを目標ドメインでファインチューン**する処方が広がっているが、既存のロバスト性ベンチは**未適応のモデルしか測らず**、適応側の研究は**目標ドメインの利得しか報告しない**。その間が空白だったという指摘
  - 5つの公開 VLA を Camera-view / Sensor-noise で調整し、**同じモデルのベースチェックポイントと** LIBERO-Plus の7摂動次元で比較。目標利得と目標外の変化、素の忘却とアーキ差を切り分ける設計
  - 数字が直截で、**10のモデル-ドメイン構成のうち8つで目標外の平均利得が負**。X-VLA は Camera-view で目標 **+69.4pt** の一方、他次元で平均 **−4.6pt**（OpenVLA-OFT は +39.3 / +1.4）。学習範囲を広げると総合利得は上がるが**次元単位の後退は消えない**
  - 手当ての効き方自体がモデル依存で、DELTA 式の特徴保存は X-VLA の目標外平均を **+1.2pt** へ引き上げるのに、OpenVLA-OFT では **−23.1pt** へ落とす。10/15 の LIBERO-RIG や 10/21 の RoboCasa-Shift が「素のポリシーがどう壊れるか」だったのに対し、こちらは**直しにいった結果どこが壊れるか**
  - 出典: [arXiv:2610.27698](https://arxiv.org/abs/2610.27698)

- **人の監督をどこまで削れるか2本 — Post-hoc Epistemic Uncertainty と SimPT**（分類: 論文, 2026-10-21）
  - **Post-hoc Epistemic Uncertainty** は「助けを呼ぶ材料」を安く作る話。アンサンブルの不一致は使えるが複数ポリシーの学習と実行が要る。提案は**単一ポリシーの埋め込みから条件付き分散を計算する kernel-variance head** で、**回帰ターゲットも勾配更新も不要、ポリシー本体は不変**。SmolVLA / LIBERO-10 で2ポリシーのアンサンブルと競合し、**スコアリング時間は最大で約1/50**
  - 評価側の指摘が鋭い。LIBERO-10 の確立したプロトコルは**主にタスク間の被覆差の検出を褒めており**、実行のばらつきがタスク内の順位付けを曖昧にする。モダリティ別ヘッドは見慣れないカメラ／指示／状態を個別に検出し、**融合ヘッドは「個々は見慣れているのに組み合わせが未知」を捉える**
  - 対になる **SimPT** は人の介入そのものをシミュで置き換える。特権的シミュ状態で進捗を追う **Agent-Compiled Progress Graph** がスナップショットを保持し、失敗後は CuRobo 製エキスパートが**進んだ段階から順に遡って復帰を試す**。固定間隔比で**復帰試行 −75.0%・復帰成功 93.4% → 98.9%**
  - この土俵で RECAP・HG-DAgger・DPO+SFT・FlowPRO を横並びにし、改良版 RECAP-CF-LPF がシミュ **76.50% → 79.36%**、実機の LAN ケーブル挿入では HIL 後訓練で **72% → 96%**。10/16 の When to Ask for Help が「いつ呼ぶか」、10/18 の SPEAR が「何を訊くか」だったのに対し、**呼ぶ材料を安く作る側**と**呼ぶ相手を機械で代替する側**
  - 出典: [arXiv:2610.29730](https://arxiv.org/abs/2610.29730), [arXiv:2610.29161](https://arxiv.org/abs/2610.29161)

- **Reasoning as a Distribution: 「計画」を一点に畳まず分布で持つと、後から操れる**（分類: 論文, 2026-10-20）
  - 行動の前に推論する VLA は増えたが、その中間決定を**単一の表現へ圧縮**するため、有効な計画が複数あるときに**選び直せたはずの選択肢が隠れる**
  - **Generative Plan Latent (GPL)** は推論状態を「どの物体・どの把持・どの経路か」の**低次元の条件付き分布**として表し、**VLA の再学習なしに**サンプリング（被覆）・要求に応じた選択（ステアリング）・結果に基づく再重み付けを可能にする
  - 効果の出方が示唆的で、π₀ + SimplerEnv で要求どおり実行される割合は **0.48 → 0.94**。ところが**同じ誘導を素の行動分布にかけても確かな利得は出ない**。介入する層が決定的ということ
  - 留保も明確で、**明示的な計画が効くのは、それが観測から既に決まっていない決定情報を担っているときだけ**。10/17 の MOSS が「flow matching のどのモードを初期ノイズで選ぶか」だったのに対し、こちらは**行動の手前の計画変数そのもの**を操作対象にする
  - 出典: [arXiv:2610.28166](https://arxiv.org/abs/2610.28166)

- **NVIDIA Flora: GR00T の裏方だった「動画→学習データ」の注釈モデル群が表に出る**（分類: 製品, 2026-10-20〜21）
  - GTC Berlin に合わせた公開。人間・ロボットの操作動画を**時刻付き行動指示（Captioner）・区間分割（TempSeg）・実行の採点（Rewarder）**へ変換する3モデル構成で、事前学習用キャプション・RL 後訓練用 process reward・配備監視用 outcome reward を**同じエンジンで**賄う
  - 位置づけが重要で、これは**ポリシーではなくデータエンジン**。GR00T の学習パイプラインを実際に支え、本番では **512基の GB300 で1日あたり20万時間**を処理するという。注釈コストは**ロボット系ワークロードで GPT-6 Astra の約1/125**と主張（指標ごとに勝ち負けは割れる）
  - 留保は2つ。**20万時間/日は大規模 GPU 群込み**でワークステーション性能ではないこと、「オープン」と言いつつ Captioner と Rewarder は **NVIDIA OneWay Noncommercial License で研究開発用途に限定**され商用配備が除外されていること
  - 同日の Isaac 側は **Isaac Lab 3.0 の GA**、Holoscan ベースの実行環境 **Isaac OS**、2,000点超の SimReady 資産、三視点同期映像と3Dハンドトラッキングの **Human 1M**、参照機体 **Agile ONE SN**（1.40m・40kg・31自由度、Jetson Thor、2027年初頭）
  - 出典: [NVIDIA Research](https://research.nvidia.com/labs/gear/flora/), [Humanoids Daily](https://www.humanoidsdaily.com/news/nvidia-flora-robot-video-training-data-models), [unite.ai](https://unite.ai/nvidia-expands-isaac-platform-with-agile-one-sn-reference-humanoid)
