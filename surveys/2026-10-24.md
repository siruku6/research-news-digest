## VLA (Vision-Language-Action) 関連ニュース — 2026-10-24

- **触覚を「買う」から「設計して刷る」へ — OpenTac と VecTile**（分類: 論文, 2026-10-22）
  - 共通の問題意識は、触覚を足す研究が増える一方で**センサ側が市販品の形状と価格に縛られており、身体や用途に合わせられない**こと。どちらも**せん断力**を安く取れるようにする
  - **OpenTac** は抵抗式の触覚スキンに**構造化した変形オーバーレイ**を被せ、接線方向の荷重を空間的な圧力分布へ変換する。隣接タクセルの**差分でせん断ベクトル、同相成分で法線力**を復号する設計。肝は生態系の方で、**2D 輪郭や可展な3D 曲面、さらには「サイズ9の靴の中敷き用センサを設計して」という文章から製造ファイルを自動生成**する CAD ツール、シミュレータ、センサ間転移、高速取得を同梱。**30種類以上のセンサを4つの実機で**作って検証し、適応的取得は 1,024 タクセルのスキンで**全面ラスタ比 19.2倍**
  - **VecTile** は徹底して安い側。圧電抵抗層に**受動的なシリコンの突起**を組み合わせ、法線とせん断を区別可能な圧力パターンへ変える。**厚さ6mm・4×4 アレイで35ドル未満**、特殊装置なしに自作できる。RMSE は法線 0.39N / せん断 0.16N で、**平らな状態で校正しても曲げて精度を保つ**。応用が具体的で、**メスが風船を貫く前に止める**のと、Diffusion Policy による電源プラグ挿入の改善
  - 10/19 の Ego2Contact が「センサが無い場所に人間動画から触覚を供給する」、10/20 の PhantomTac が「磁気式センサの物理層を攻撃する」だったのに対し、こちらは**センサそのものを誰でも作れる物にする**側
  - 出典: [arXiv:2610.31661](https://arxiv.org/abs/2610.31661), [arXiv:2610.31472](https://arxiv.org/abs/2610.31472)

- **Externalise the Memory: 「記憶は重みに焼くべきか、外に置くべきか」を事前登録で測る**（分類: 論文, 2026-10-21）
  - 構成が珍しい。**仮説・条件群・検定・解析規則を学習前に、かつ p 値を見る前に事前登録**したうえで実験している。記憶付き教師（過去の試行から教訓とその画像を検索する VLM）が軌跡を生成し、そこから LoRA の生徒ポリシーを蒸留して揃えたプロトコルで比較する
  - 結果の出し方が誠実で、**記憶付き挙動を重みへ蒸留しても行動のみの対照条件に +1pt（有意差なし）**。しかも登録済み検定は**自分で設定した最小効果量に対して検出力不足**だったとして、「記憶を重みに持てる」という主張を**反証ではなく取り下げる**と明記する
  - 一方で、**固定した生徒の重みに教師の凍結済み検索バッファを後付けすると +34pt（z=5.15）**で、記憶付き教師の参照値（49.3%）に到達。追加対照では**同じバッファがアダプタ無しの素のモデルを 48% へ、他の3つのアダプタを 19〜26% から 53〜55% へ**引き上げ、**バッファを付けた後はアダプタが何も足していない**
  - 探索的なプローブの解釈も鋭く、行動蒸留は**周辺的な補正は渡せても、検索が供給する「状況依存の条件付き補正」は渡せない**。より難しい第2タスクでは利得が +6pt（95%CI −4.5〜+16.4）に留まり、**記憶の被覆率**で説明している。9/26 の MemBodied 以降の記憶系が「どう持つか」を競っていたのに対し、こちらは**そもそも置き場所を統制実験で決める**側
  - 出典: [arXiv:2610.30478](https://arxiv.org/abs/2610.30478)

- **動画と行動の対応を、取り出す側と採点する側から — SkeLAM と RGraph-Eval**（分類: 論文, 2026-10-22）
  - **SkeLAM** は latent action model の根本的な汚れを突く。再構成で駆動される潜在行動は**ロボット自身の動きと、物体の反応や他のシーン変化が混ざる**ため、実際の制御入力との対応が崩れる。対策は潜在行動を**運動学成分と残差成分へ分離**し、**RGB 由来とスケルトン由来の運動学表現が動画再構成中に入れ替え可能になるよう cross-modal swap reconstruction で訓練**する。DreamDojo 比でエンドエフェクタ誤差が減り、ゼロショットの動作転移と、**予測成功率と実成功率の高い一致**を示す
  - **RGraph-Eval** は生成側の採点。問題設定の一文が的確で、「**生成されたロボット動画は、もっともらしく見えながら違う相互作用を描いていることがある**」——違う物体が動く、把持が消える、置き場所が目的地の外になる。時間方向のシーングラフで**タスク実体・相互作用・運動**を統一表現にまとめ、基盤モデルで操作役割の同定・マスクのグラウンディング・状態遷移の推定・3D 運動の復元を行い、**可視物体・関係変化・3D 経路幾何**の3観点で採点。ShareRobot 由来の 1,000 シーンに注釈を付けた ShareRobot-SG を公開し、3つの動画生成器を評価して人間判断との整合を確認
  - 10/22 の NVIDIA Flora が「動画を学習データへ変換するエンジン」、10/13 の CASTER が「動画生成モデルにデモを作らせる」だったのに対し、こちらは**その生成物が本当にタスクとして正しいかを測る定規**と、**動画から取り出す行動を身体の動きに揃える手当て**
  - 出典: [arXiv:2610.31474](https://arxiv.org/abs/2610.31474), [arXiv:2610.31121](https://arxiv.org/abs/2610.31121)

- **誰に操作権を渡すかを設計する2本 — CARE と TEAR**（分類: 論文, 2026-10-22）
  - 共通の構図は、**実行中にどの制御源が権限を持つべきかをロボット側でオンライン判断する**こと。相手がクラウドモデルか人間かで分かれる
  - **CARE** はクラウドとローカルの間。強いクラウドエージェントは**連続する行動の間に数秒プラットフォームを遊ばせ**、軽量ローカルは速いが誤りやすい。既存の階層構成は役割を固定し、通常のモデルルータは**状態を持たないリクエスト単位の判断**をする。提案は軽量な critic が実行の信頼性を監視して昇格を起こし、**一度上げたら回復するまで握り続ける**（ステップ単位の往復を避ける）。**共有ハンドオフメモリ**が実行文脈と進捗を引き継ぐので、介入側はやり直しから始めない。最強の協調ベースライン比 **+6.3〜18.3pt**、クラウド単独に迫りつつ**行動間レイテンシの中央値を 28.8〜82.6% 削減**
  - **TEAR** は人間と自律の間。遠隔操作は接触の濃い場面に強いが通信が要り、ローカル自律は独立して動けるが**意味的な曖昧さや想定外に弱い**。エッジ側で**通信状態（遠隔操作が可能か）とタスク意味の整合性（自律が妥当か）**を併せて見て、軽量な時間的アービトレータが権限移譲のタイミングを決める。**人間の介入を全操作の 19.8〜27.4% に抑えたまま人間単独と同等の成功率**、自律単独比では 30〜40% 改善
  - 10/16 の When to Ask for Help が dual-system VLA の**内部で遅い側をいつ呼ぶか**だったのに対し、こちらは**プロセス境界やネットワーク境界をまたぐ権限の受け渡し**。後述の韓国 K-On-Device が「そもそもクラウドに出さない」と賭けているのと対置できる
  - 出典: [arXiv:2610.30587](https://arxiv.org/abs/2610.30587), [arXiv:2610.30819](https://arxiv.org/abs/2610.30819)

- **韓国、オンデバイス VLA を国策に — 8,002億ウォンの K-On-Device でヒューマノイド主管に Mobilint**（分類: 業界動向, 2026-10-22）
  - 産業通商資源部（KEIT 管理）の **K-On-Device AI 半導体技術開発事業（約8,002億ウォン / 約6.06億ドル、2026〜2030年）**で、ヒューマノイド分野の主管研究機関に Mobilint が選定。担当は**チップ本体・コンパイラ・モデル実行環境、最終的に配備可能なアクセラレータモジュール**まで
  - 技術的な論拠が明快で、現行 VLA は**約 50Hz（20ms ごとに1推論）**で回す必要があるのに、**クラウド往復は 100〜300ms** かかり予算を丸ごと超える。記事は「ヒューマノイドにおけるクラウド依存 AI は遅いのではなく**安全上の障害モード**」と踏み込む。同社の REGULUS SoC は **3W 未満で 10 TOPS 超**を主張し、**2段構成の VLA パイプライン向けのハード・ソフト協調設計**だとする
  - 布陣は、ファウンドリに Samsung、EDA に Synopsys / Cadence、需要側に Hyundai Motor・LG Electronics・Doosan Robotics・韓国航空宇宙産業。**VLA モデル側の圧縮は Nota が担当**し、トークン圧縮・量子化・枝刈り・蒸留で NPU の仕様へ合わせる
  - 留保は TOPS 値が精度形式（INT8/INT4/FP16）で変わり**他社比較に耐えないこと**、性能・工程の独立検証が無いこと。10/23 の Dream Labs が「**脳を時間貸しのクラウド API で売る**」だったのに対し、こちらは**制御周期を根拠にクラウドを排除する**真逆の賭け
  - 出典: [TechTimes](https://www.techtimes.com/articles/329411/20261023/mobilint-tapped-lead-koreas-606m-device-ai-chip-program-humanoid-robots.htm), [Seoul Economic Daily](https://en.sedaily.com/technology/2026/09/08/lg-nota-mobilint-to-build-humanoid-robot-on-korean-made-npu)

- **データの仕入れ方で割れる2社 — Figure の Index（3,750万本）と AgiBot World Release 4（注釈で勝負）**（分類: 業界動向 / 製品, 2026-10-22〜23）
  - **Figure** の全社会議で開示された数字が生々しい。人間動画収集アプリ **Index は 112か国・126万ダウンロードから 3,750万本のアップロード**を集め、**週あたりのデータ支出は約810万ドル**。同社自身が**アップロード数は洗浄済み学習映像と等価でない**と断っている。併せて Figure 04 が設計ロック、Figure 03 は1,000台目を製造し 02 比で**コスト9割超削減**、手は4世代目で**指先トラッキングがミリ単位**。**Helix 3.0** は「より多くのデータと GPU で学習した」として社内結果を "baby AGI" と形容するのみで能力は非開示（直近の Helix 2.5 は**未知の家庭で成功率 56%**）
  - **AgiBot** は量ではなく注釈の中身で差を付ける。**AGIBOT WORLD Release 4「Physical Reasoning」**は、実行の動きではなく**状況が変わったときに次に何をするかという判断のロジック**を対象にし、上位指示→サブタスク→個々の行動を結び、**対象物体・操作位置・グリッパ状態・期待される結果・記述と運動経路を結ぶ空間ラベル**を付す。**成功例だけでなく誤り例も含め**、正しい物体を選べたか・数量条件を満たしたかまで記録。自社の次世代基盤モデルとエージェント枠組みの学習に既に使っているとする
  - ただし **Release 4 はエピソード数も定量評価も非開示**、ライセンスは **CC BY-NC-SA 4.0 で商用利用は不可**。報道側も「**収集例の外でも正しい次の行動を選べるかが本当の試金石**」と留保する
  - 10/22 の NVIDIA Flora が「動画→学習データの変換を道具として売る」だったのに対し、**クラウドソーシングで生の量を積む側（Figure）**と**判断の根拠を注釈として構造化する側（AgiBot）**という分岐になっている
  - 出典: [Humanoids Daily (Figure)](https://www.humanoidsdaily.com/news/figure-all-hands-figure-04-index-data-helix-3), [Humanoids Daily (AgiBot)](https://www.humanoidsdaily.com/news/agibot-world-release-4-physical-reasoning-dataset)
