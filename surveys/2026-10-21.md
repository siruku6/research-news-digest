## VLA (Vision-Language-Action) 関連ニュース — 2026-10-21

- **成功率の集計では見えないものを掘る2本 — Failure Attribution と RoboCasa-Shift**（分類: 論文, 2026-10-19〜20）
  - 共通の問題意識は、**「成功率が何pt落ちた」という集計量が、どこで・何のせいで崩れたかを消してしまう**こと。片方は原因の帰属、もう片方は崩れた場所の特定に向かう
  - **Failure Attribution** の問いが鋭い。「この汚れが有害だ」と分かっても、**それを取り除けば今のエピソードが救われるのかは別問題**で、複数の劣化が同時に乗っているときに効くのはどれか。シーンと劣化を別表現に分解した factorized risk model を学習し、**潜在空間での介入**で除去利得を見積もる。肝は実用面で、**クリーンな対照画像も反実仮想のロールアウトも不要**、現在の画像とタスク指示だけで済む。OpenVLA・π0.5（シミュ）と π0.5-DROID（実機 Franka）で、フロンティア VLM 比 **帰属誤差が約1/3**
  - **RoboCasa-Shift** は RoboCasa365 上の診断ベンチ。単一要因の摂動を、**設定を揃えてその要因だけ違う clean-perturbed のペア**で回し、シミュレータ由来の段階情報で採点。GR00T N1.5・長時間4タスク・4要因 × 3段階・計 1,040 ロールアウト
  - 数字が効く。あるカメラ条件は **ΔSR=0 なのに、対になった 80 エピソードのうち 8 件で勝敗が入れ替わっていた**。さらに Camera L₂ と Gaussian blur L₁ は**どちらも ΔSR=0.188 なのに、第1段階での失敗率は 19.0% と 36.4%** と別物
  - 10/15 の LIBERO-RIG が「ロボット側の構成を振って脆さの地図を引く」、10/20 の Coverage Shift が「判定器の有効性が学習で動く」だったのに対し、こちらは**同じ集計値の裏にある別々の壊れ方**を扱う
  - 出典: [arXiv:2610.27277](https://arxiv.org/abs/2610.27277), [arXiv:2610.27861](https://arxiv.org/abs/2610.27861)

- **デモを採る側の「見せ方」と「道具」を設計変数にする2本 — PointHand と UMI Glove**（分類: 論文, 2026-10-20）
  - **PointHand** の着眼点が良い。模倣学習は素人オペレータのデモに依存を強めているのに、**操作中に本人へロボットをどう描画して見せるかが、集まるデモとそこから学ぶポリシーに与える影響は調べられていなかった**。多指ハンドを**ポリシーが観測するのと同じキーポイント**として描く
  - 素人18名・熟練4名で 2,200 試行。手の実形状／全キーポイント強調／**親指と人差し指だけ強調**の3条件で、親指＋人差し指条件は 600 試行中 **441 本成功**（実形状は 320 本）。さらに同じデモが、点群ポリシーでは3条件中**最弱（46.3%）**なのに、キーポイントポリシーに替えると**最強（57.3%）**へ反転（5シード全てで +11.0pt）
  - 結論は「デモの価値は**収集時に見せた描画と、ポリシーが観測するものの組**で決まる」。10/20 の GazeAct が「操作者の視線を学習時の教師に借りる」だったのに対し、こちらは**操作者に何を見せるかを操作する**側
  - **UMI Glove** は道具側。手持ち収集デバイスは手首カメラ・ケーブル・姿勢トラッカを手に背負わせ、パイプラインには**同期と相互校正の要るストリームの数だけ負担**を載せる。これを **122ドルの頭部カメラ1台**に畳む。**22ドルの電子部品ゼロのグローブ**の印字フィデューシャルを紙タイル越しに読み、**ポリシーが見るのと同じフレームから**ラベルが出る
  - 実機エンコーダ比で中央値 **6.5mm / 1.6度**、フレーム被覆 93〜100%、検証損失の代償は 3%。遠隔操作48エピソードにグローブ194本を足すと **10/25 → 17/25**（遠隔操作172本単独の 18/25 と同等）、共訓練した頭部カメラ版は **20/25**（手首カメラ 15/25、固定カメラ 12/25）。10/19 の Hardware-as-Regularization が「収集ハードの物理で歪みを減らす」だったのに対し、こちらは**センサの本数そのものを減らす**
  - 出典: [arXiv:2610.27907](https://arxiv.org/abs/2610.27907), [arXiv:2610.27622](https://arxiv.org/abs/2610.27622)

- **ACE-Brain-0.6: フロンティア優位の正体を「空間グラウンディング」と見て、9B で抜きにいく**（分類: 論文, 2026-10-19）
  - 出発点は観察で、GPT-6 Astra や Claude Opus 5.5 の汎用性には**強い空間知覚が伴っており、妨害物のなかでも「どこに触るか」を当てられる**。ならば**グラウンディングを規模で押せば土台が強くなるはず**、という賭け
  - ロボット操作の収録を自動注釈し、多様な視覚データと混ぜて**検証可能なグラウンディング監督**へ変換するパイプラインを構築。**約150万サンプル**で Qwen3.5-9B をファインチューン
  - 結果は**公開7ベンチのうち4つで GPT-6 Astra を上回り、総合平均 75.41 対 73.68**。学習設定を固定したままデータの版を重ねるほど性能が単調に伸びる、というスケーリング側の報告も添える
  - 10/19 の GPT-6-Astra 検証レポートや 10/20 の Bitter Lesson が「**フロンティアがどこまで来たか**」だったのに対し、こちらは**その優位の源を一軸に絞って公開 9B で埋めにいく**逆方向
  - 出典: [arXiv:2610.27040](https://arxiv.org/abs/2610.27040)

- **JARVIS: 言語指示を与えず、「組立説明図」だけで組み立てさせる**（分類: 論文, 2026-10-20）
  - 視覚マニュアルは手順知識を図で伝えるが、**追加の言語指示なしにそれを長時間の実行へ落とす**のは別の難しさがある、という設定。手法非依存のベンチとして **8,987シーン・236,679 の LEGO 組立タスク**、対話評価用に **JARVIS-v1 の50タスク**
  - 採点が構造を見る。幾何精度・構造的関係・**組立順序**・部分進捗・完成を分けて測る。併せて、ロボットのプリミティブを実行可能なプログラムへ合成し**実行フィードバックで検証と復帰を回す** JARVIS-agentic を提示（タスク固有の軌跡もパラメータ更新も不要）
  - 9モデルでの結果が示唆的で、タスク指向のプリミティブを与えると平均スコアは上がるが、**ホライズンが伸びると急落し、実行時のミスは依然として直せない**。**過去タスクの経験は初期性能を上げる一方、反省の反復は効いたり効かなかったり**
  - 同日の **Embodied Playground**（410環境・EP-100 を5スイート16タイプで厳選）と合わせ、長時間の身体タスクで**計画と実行を繋ぎ続けられるか**を測る土俵が立て続けに出ている
  - 出典: [arXiv:2610.27618](https://arxiv.org/abs/2610.27618), [arXiv:2610.27039](https://arxiv.org/abs/2610.27039)

- **Eka Robotics が $150M 調達 — VLA の "L" を外し、"vision-force-action" に賭ける**（分類: 業界動向, 2026-10-20）
  - a16z と F-Prime Capital がリードする Series A で **1.5億ドル、ポストマネー 14.5億ドル**。Obvious Ventures・E14 Fund・Samsung Next ほかが参加。創業陣は **Pulkit Agrawal（MIT 教授）と Tuomas Haarnoja（元 DeepMind、Soft Actor-Critic）**
  - 主張の核は名前どおりで、言語ではなく**接触時に感じる力**を視覚と並ぶ一次信号に置く **VFA (vision-force-action)** モデル。**人間のデモに頼らずシミュレーション内の大規模 RL で物理の直観を作る**（AlphaZero の自己対戦を引き合いに出す）。視覚は主に対象の位置特定に使う、という役割分担
  - 公表値は **毎時1,500オペレーション（人間基準の約2.5倍）**で、学習分布外の物体も扱えるとする。電球のねじ込みと配線の挿入を同じロボットで、という例示
  - 留保は大きい。**成功率の定義・ハードウェア構成・アーキテクチャ詳細・顧客・導入時期はいずれも非開示**で、報道側も独立検証がないこと、**本番シフトでの持続性能が次の試金石**であることを明記
  - 10/16 の NEURA Neuron AI や 10/19 の RLWRLD RLDX-1 が**VLA に足す**方向だったのに対し、こちらは**言語を引く**方向。10/17 の Natura-1（手の器用操作に全振り）と並べると、賭け方の分岐がさらに広がっている
  - 出典: [Humanoids Daily](https://www.humanoidsdaily.com/news/eka-robotics-150-million-series-a-vision-force-action), [Eka Robotics](https://ekarobotics.com/blog/eka-robotics-raises-150m-to-build-superhuman-intelligence-for-the-physical-world)
