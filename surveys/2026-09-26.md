## VLA (Vision-Language-Action) 関連ニュース — 2026-09-26

- **MemBodied: VLA に固定サイズの「エピソード記憶」を持たせる**（分類: 論文, 2026-09-23）
  - VLA は現在の観測より前の情報をエピソード単位で保持できないという課題に対し、ポリシー呼び出しをまたいだ相互作用を記録する「連想状態」と、初期シーンを圧縮保持する「エピソードアンカー」の2要素からなる固定長メモリを導入
  - 記憶依存タスク（RMBench 5種）で、状態を持たないポリシーの7.81倍の平均成功率。単純な再帰メモリ比2.98倍、最強のメモリ拡張ベースライン比1.3倍を10分の1のパラメータで達成
  - LIBERO-Long でも90.6%（ベースポリシー比 +5.4pt）。コンテキスト長を伸ばす方向とは別の、軽量な代替策として提示
  - 出典: [arXiv:2609.28256](https://arxiv.org/abs/2609.28256)

- **Decoupled Early Exits: フローマッチング VLA の計算量をタスク別に割り当てる**（分類: 論文, 2026-09-24）
  - バックボーン深さ V・アクションエキスパート深さ A・ノイズ除去ステップ数 D の3軸を独立に設定可能な「早期終了」として露出させ、中間層に軽量 Exit Transformer と KV キャッシュ合成を追加
  - SmolVLA・π0.5 上の LIBERO / Meta-World で レイテンシ −79.2%、FLOPs −31.8% に対し成功率は平均 +5.6% と、速度と精度を同時に改善
  - 追加パラメータは SmolVLA で2.1%、π0.5 で4.1%。最適な計算配分はタスクごとに異なり、3軸が相補的に効くことを示した
  - 出典: [arXiv:2609.29382](https://arxiv.org/abs/2609.29382)

- **RoboTwin-Phys: 「物理条件の多様性」を評価軸に加えたベンチマーク**（分類: 論文, 2026-09-22）
  - 既存シミュレーションベンチは視覚・レイアウトを変えても物理パラメータは固定という指摘から、質量・摩擦・関節ダイナミクスなど13属性を現実的な範囲で連続的に変動させる
  - 物理パラメータの真値付き専門家デモを5,000件超提供し、VLA と WAM（World-Action Model）を統一条件で評価
  - 視覚・レイアウトのランダム化には強いモデルでも、物理条件が変わると顕著に性能が劣化することを確認。頑健性評価の抜け穴を可視化した
  - 出典: [arXiv:2609.26292](https://arxiv.org/abs/2609.26292)

- **Figure の Brett Adcock CEO「ヒューマノイドは LLM 以上のデータと計算資源を要する」**（分類: 業界動向, 2026-09-22）
  - RoboStrategy インタビューの抜粋を X に投稿し、ヒューマノイド開発を「①有能なハード → ②エンドツーエンド自律 → ③知能のスケール → ④量産」の4段階に整理
  - Figure は現在③の知能スケール段階に入っており、能力拡大にはデータと計算の投入拡大が鍵で、最終的には数千億ドル規模の投資が必要になるとの見解
  - VLA 系ポリシーのスケーリング則が LLM の水準を超えるコストになるという主張で、上記の効率化・データ効率研究が実務的に重要になる背景を裏付ける
  - 出典: [Humanoids Daily](https://www.humanoidsdaily.com/news/brett-adcock-humanoids-data-compute-llms)
