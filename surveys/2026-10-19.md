## VLA (Vision-Language-Action) 関連ニュース — 2026-10-19

- **フロンティアモデルを実機で測る2本 — GPT-6-Astra 検証レポートと HexaShell**（分類: 論文, 2026-10-15〜16）
  - **Has GPT-6-Astra Achieved Embodied Intelligence?** は、卓上操作・ヒューマノイド・移動体・多指ハンドにまたがる**12ベンチの統一プロトコル大規模評価**。ICL を許し実行ステップ数を大幅に増やすと単体で前例のない性能に達する一方、結論は「**embodied competence の閾値は越えたが、practical embodied intelligence には届いていない**」。実機8構成で ①ICL 用デモの収集コストが高い ②物理制約下では**実行時間を延ばして成功率を買う取引が成立しない**、の2点を壁として示す。次世代ベンチ試作も提示し、**ドメイン内デモを与えず、考えている間も止まらない「世界時計」で採点する**
  - **HexaShell** は逆にハーネスを極限まで薄くして VLM コーディングエージェントの限界を測る。双腕を1本のコマンドラインで駆動し、失敗ログを読んで**学んだことをコード（ツール）として残す**。RoboDojo 全42タスクで成功率 **39.7%** の SOTA。ただし**限界は推論ではなく接触**で、押し 92.5%・記憶タスク 65.0% に対し**嵌合は 8.3%**。失敗時はたいてい原因を正しく見ているのに動作を作れない
  - 10/17 の AA-Robotics が第三者の**横並び採点**だったのに対し、こちらは**能力の上限と壁の所在**まで踏み込んでいる
  - 出典: [arXiv:2610.22471](https://arxiv.org/abs/2610.22471), [arXiv:2610.23479](https://arxiv.org/abs/2610.23479)

- **人間デモの「不正確さ」を、ハードで直すか事後に重みづけるか — Hardware-as-Regularization と PRIME**（分類: 論文, 2026-10-16）
  - **Hardware-as-Regularization** は、安価な受動リーダアームが**復元力を欠くため冗長自由度が拘束されず関節軌跡が著しく不安定になる**点を突く。機械式クラッチ＋3Dプリントのうず巻きばねで各関節を中立姿勢へ引き戻すと、これが**関節空間 L2 正則化と等価な物理的事前分布**として働く。下流の成功率は Block Stacking で **36.7% → 73.3%**。**剛性を下げるほど一貫性が単調に悪化する**ことを掃引で示し、剛性＝正則化の重みという読み替えを裏づける
  - **PRIME** は同じ問題を学習側で扱う。既存の progress estimator は**デモ内の全行動が成功に寄与する**と仮定するため、高精度操作では**人間のミスを「進捗」と誤読して報酬学習ごと壊す**。観測状態の重み付きグラフを張り**最短路探索で成功までの測地距離を近似**、その変化量で前進・停滞・後退を区別し**時間方向の単調性を仮定しない**。充電器挿入では SFT 比 **最大5倍**
  - 10/15 の AXIS-Bench が「劣悪デモに質タグを付けて条件づける」だったのに対し、**収集時の物理で歪みを減らす側**と**軌跡内のどの行動が効いたかを事後に測る側**
  - 出典: [arXiv:2610.22977](https://arxiv.org/abs/2610.22977), [arXiv:2610.23769](https://arxiv.org/abs/2610.23769)

- **Ego2Contact: 触覚センサを付けずに、人間の一人称動画から「触覚」を予測して渡す**（分類: 論文, 2026-10-16）
  - 接触位置と力は不可欠だが**ロボットで測るには専用ハードが要りデータが慢性的に足りない**。一方で人間の一人称動画はスケールするが触覚がない、という供給の非対称性が出発点
  - 先行の動画→触覚予測器は**人間の手に閉じており**、外見もタクセル配置も違うロボットハンドへ渡らなかった。Ego2Contact は時間方向のシーン文脈と手の局所視覚特徴を融合して**双手の触覚場**を推定し、**解剖学的な領域対応**でロボット側のタクセル配置を正準グリッドへ整列。ロボットの実測値が教師に、予測値がポリシー入力に変わる
  - シミュ RL と実機の後訓練の双方で、**予測触覚を使うポリシーが非触覚ベースラインを上回り、真の触覚の利得の一部を回収**。9/29 の Uni-VLaT や 10/15 の ForceBench が「センサを付けた上でどう入れるか」だったのに対し、**センサがない場所に人間由来の事前分布で触覚を供給する**
  - 出典: [arXiv:2610.22932](https://arxiv.org/abs/2610.22932)

- **VLA-Fabric: 1腕1 VLA のまま、ポリシー境界を越えて協調を学習させる**（分類: 論文, 2026-10-16）
  - 多腕協調は中央集権的な単一ポリシー・上位の役割割り当て・相手に反応するローカル実行のいずれかで組まれてきたが、「**完全な VLA 同士が行動生成の最中にどう相互作用すべきか**」は空白だったという指摘
  - **腕ごとに完全な VLA を置き、知覚と行動の所有権をローカルに保ったまま**境界を越える相互作用を学習。どこで・どう集約し・どう学ぶかを系統的に調べ、共有文脈／相手固有の潜在情報／行動段階での相互作用という3機能を同定。**構造の異なる VLA アーキテクチャに移植しても成立**し、3腕・4腕チームの**実機4タスク全てで独立学習比 +16〜40pt**
  - 10/15 の Coordi-π が単一ポリシー内の左右トークン分離だったのに対し、こちらは**ポリシーを分けたまま台数方向にスケールさせる**側
  - 出典: [arXiv:2610.23018](https://arxiv.org/abs/2610.23018)

- **RLWRLD、触覚・力を扱う基盤モデル RLDX-1 を大手町の公道沿いで実証**（分類: 業界動向, 2026-10-15〜16 実施）
  - 三菱地所・TMIP との「まちまるごと実証実験 by TMIP」第4弾。大手町仲通りで**来街者への飲料の手渡しと空容器の回収**を実演し、RLWRLD が機体・事前検証・当日運用・安全管理を担う
  - RLDX-1 の位置づけは**視覚言語に加えて力（トルク）・触覚・ワーキングメモリを単一モデルで扱う**こと。変形物操作、遮蔽下の収納、両手での液体注ぎを想定。同社は**公開ベンチ8種で GR00T や π0 を上回った**と主張
  - 留保は大きく、ベンチの内訳・プロトコル・パラメータ規模はいずれも非公開。**報道側も「あくまで同社の主張」と明記**し、現地実証も成功率・介入回数の公表はない
  - 10/16 の NEURA Neuron AI（視覚＋触覚＋音＋記憶）と足し算の中身がほぼ重なる一方、**デモの場が展示会ではなく一般の街路**である点が違う
  - 出典: [ロボスタ](https://robotstart.info/article/2026/10/08/382498.html), [三菱地所](https://www.mec.co.jp/news/detail/2026/10/08_mec261008_tmip)
